# Stage-53结果复核：单状态几何保持改变了失效路径，但未保住总体收益

用户已报告`REVIEW_NATIVE_GEOMETRY_PRESERVATION_PILOT`，并提供scope_summary、policy_summary、retention_summary、focus四张完整表。以下数字来自用户终端及直接算术核对；本机未持有服务器完整模型、轨迹、preparation支持表和decision原件，未独立重验全部哈希与预算。paired区间及总体逐种子差尚未提供，不推断显著性。Stage-1～53实验Python源码与既有结果保持冻结。

**本轮没有达到“保留多数适配收益，同时减少长期失效”的目标。** 保持项确有几何梯度，两种保持均改善了部分恢复行为，但0304更严重、0204原有高分分支丢失，原先10条获益视频的平均收益也下降。当前结果限定的是这套固定状态、单Hann格点及固定系数的保持方案，仍为后续跨状态能力保持提供了具体问题。

## 实现与暴露核对

8条scope记录均为响应／BN缓冲冻结、固定响应误差0、响应梯度0、匹配控制抽样True；每个模型训练1,661,892参数，普通监督1,024视图。anchor_all最大保持梯度1.8119～1.9187，anchor_reliable为2.2740～2.5480，说明保持项确实作用于几何参数。

每种子两组的资格暴露完全一致：fold0为843／856视图（82.32%／83.59%），fold1为706／719视图（68.95%／70.21%）。有条件组实际平均权重0.97097～1.00104，与全状态组1.0接近；不能把结果解释为资格样本几乎不存在或保持项未启用。实际梯度范数仍不同，匹配平均权重不等于匹配梯度。

训练平均保持误差约0.0107～0.0203，是各自抽样和权重下的训练读数。当前没有geometry_control在同一批特征上的对应误差，不能仅凭这些数值断言相对控制的功能漂移已经降低。固定特征响应不变也不保证沿自身新状态的响应或选点不变。

## 固定五视频的路径取舍

以下均先平均两个种子，由focus保留8位小数直接计算：

**0304：保持没有保护原稳定轨迹，且出现更早失效。** geometry_control两个种子都1083首次失效。anchor_all两个种子都555失效至末尾，均值对控制−22.2567、对原生−49.7019。anchor_reliable的2132为1091失效、2133为555失效，均持续到末尾；均值对控制−11.4631、对原生−38.9082。

两种新组响应参数和固定输入响应都保持不变，仍能在555首次失效。这说明早期555附近的路径不要求更新响应参数；不能仅按与旧模型相近的失效时刻归因于某个塔。新事件是否同样属于中心跳变或尺寸问题，仍需本轮轨迹几何，不能套用Stage-49的测量。

**0307：全状态保持带来了最清楚的局部改善。** 控制385首次失效后两个种子均未恢复；anchor_all首次失效397／396，两种子均能恢复，分别记录534／710和509，末尾未恢复均0，视频均值对控制+18.5237。其AUC56.3868仍低于原生66.5098。

anchor_reliable的2132在387首次失效后未恢复，2133在395失效，记录473／709恢复，末尾未恢复0。其视频均值对控制+10.5245，但比anchor_all低约7.9992。资格选择没有在这条视频上带来更好的保持，不能预设“仅保持正确fit状态”必然优于全部状态。

**0176：高分种子的首次事件推迟，末尾未恢复消失。** 控制2133首次失效160、240恢复且后续有末尾未恢复；anchor_all的2133首次事件推迟到407，412恢复，末尾未恢复0，AUC68.6575。anchor_reliable的2133首次事件381，385／413恢复，末尾未恢复0，AUC68.6882。

这次改善包括避免／推迟原先的早期事件及后续状态变化，不应只称为同一失败后的恢复增强。2132仍在159首次失效并持续到末尾，AUC约15.6；两种保持在该视频的改善仍存在明显种子依赖。

**0204：原有无失效高分分支丢失。** 控制2133为77.9691且无失效，anchor_all降至55.7107，在664失效、894恢复；anchor_reliable降至55.9640，在664失效、892恢复。2132方面，控制664失效后未恢复，anchor_all893恢复，anchor_reliable仍未恢复。

因此保持同时改善了一个种子的末尾恢复、损伤了另一个种子的失效避免，视频平均对控制分别−11.1344／−12.0263。两种平均AUC仍略高于原生，不能仅按是否仍有正收益忽略原有大幅收益的丢失。

**0226：正常恢复保留，但AUC回落。** 控制AUC58.3116、恢复338／340；anchor_all为56.2071，记录2132的235／339与2133的338恢复；anchor_reliable为56.6564、恢复338／339。两组仍高于原生55.0614，但相对控制分别−2.1045／−1.6551。单个较早恢复不等于完整轨迹更好。

## 局部恢复读数的边界

固定geometry_control失败队列有9个支持视频，anchor_all对控制AUC+5.6457，anchor_reliable+2.5744；两者仍低于原生26.8452。此队列由控制结果定义，不能与Stage-52的joint失败队列直接比较。队列上改善也没有转为完整视频改善。

anchor_all平均末尾未恢复事件从控制0.4583降至0.2917，恢复事件从0.2083增至0.4583；anchor_reliable分别为0.3750／0.3750。与此同时，两组失效事件均从0.6667升至0.7500，复发从0.0417升至0.0833。各自轨迹的事件起点、数量和后续状态不同，不能把恢复次数增加直接当作同起点恢复概率提高。
