### 0304：好候选没有进入最后的两框比较

第554帧pulse最终IoU为0.8008，第555帧突然降至0。第555帧PPO选q2，外观最终换成q0，两者IoU均为0，而四候选最佳为0.8138。因此至少一个好框位于q1／q3。

现有外观规则只比较PPO框与一个challenger，最终只能在这两者之间选择。由上述不同槽位可知，该帧实际比较的是q2与q0，好框没有进入这次外观二选一。这项判断来自候选槽位与原选择代码，不要求猜测响应峰值。

该帧实际历史外观引用为553、550、547，其预测IoU分别0.8206、0.7825、0.8078，均为好框。不能把此处失败简单解释为历史全被低IoU写入污染。第555帧也没有启用pulse尺寸替换，尺度引用为空。

Stage-101从548帧共同状态取消最近一次调整后，548～563的最终输出完全没有分叉；Stage-102的`first_output_difference`为空，PPO／最终选择／写入／外观引用也未分叉。这比仅比较窗口均值更明确：该次取消没有修复555错误，需检查此前状态与当前核验范围。

整条0304／2172轨迹中，gated无好候选58帧、pulse为1,227帧；pulse低IoU1,171帧，其中1,033帧被接纳写入尺寸库。长时间缺框是重要后果，但555首发处仍有好候选。

### 0169：本帧错选发生在低IoU写入之前

第652帧pulse最终IoU为0.5970，第653帧PPO与最终均选q3、IoU为0，另一公开候选达到0.6511；裁剪最大覆盖为1。本帧`used_history=false`，不能认定是历史外观均值强行覆盖了PPO。

gated同一视频、同一帧也由PPO选到了IoU为0的q3，但外观最终换成q1，得到0.5964。两条过去轨迹已经不同，不能据此声称把gated的外观决策直接移到pulse历史就必然修复。它说明当前核验条件和可访问候选值得继续检查。

第653帧pulse拒绝记忆写入，且未启用尺寸替换。取消646那次替换只使646～661均值由0.2902升至0.3203，末帧仍为0。整条轨迹无好候选由67帧增至460帧、低IoU由4增至460帧，严重损伤尚未解决。

### 写入资格没有阻止普通搜索历史接纳错框

当前实现对可信尺寸库执行有条件更新，但对普通几何历史始终执行：

```python
s97.update_sizes(sizes, frame, box, accepted, design)
history = (history + [box])[-ap["design"]["history"]:]
```

因此0304／555与0169／653虽然`memory_write=false`且`scale_written=false`，错误最终框仍进入下一帧普通候选的搜索中心／尺寸输入。已有记忆资格保护覆盖不到这条路径。 [执行代码](../../../tools/stage100_online_scale.py)

代码和完整状态重建能够确认这条依赖；本轮尚未通过新干预证明，阻断该路径就能保住整视频精度及恢复。此前的旧中心保持、尺寸限制等结果仍需纳入对照，不能将“拒绝几何写入”直接视为成功方法。

## 触发与引用删除的总体证据

1,834对同状态触发的分类为：

| 情况 | 状态数 |
|---|---:|
| 两组均选中好框 | 1,110 |
| 两组均无好候选 | 656 |
| 两组有好候选但均未选中 | 36 |
| 跳过后丢掉／补出好候选 | 10／3 |
| 两组均有好候选，跳过后救回／破坏最终选择 | 9／10 |
| 无效GT | 0 |

不能用全部339胜338负的IoU微差，替代这些供给与选择环节的分类；也不能把656个无好候选状态解释为再训练选择器就能当帧解决。

在两条完整缓存上共检查262,146条实际引用边。其中低IoU尺寸引用2,219次，删除一条会改变裁剪1,390次，约62.64%；好框尺寸引用删除也有3,063/5,641次改变裁剪。尺寸删除只计算输入几何，不提供删除后的预测收益。

低IoU外观引用34,742次，逐条删除后的当帧IoU为601胜、33,530平、611负；好框引用删除为9,760胜、184,310平、9,660负。低IoU引用确实被规则接纳、读取，并可能改变选择，但这些计数没有支持简单逐条删除就能整体修复。单条删除不会修复其余历史或重新推进长期轨迹；同帧多条引用和多次读取也不是独立样本。

## 后续实验依据

优先比较现有两框外观核验与覆盖全部四候选的核验，量化是否让原本存在的好框真正进入决策；再独立检验“输出框”和“下一次搜索所接纳的几何状态”是否需要不同的提交条件。必须保留原PPO＋gated对照、相同搜索预算及完整轨迹稳定性和恢复检查。

0304／0169用于检验有好框的错选及状态传播，0307用于防止恢复能力被外观覆盖，0076则代表公开候选确实缺失的边界。单纯追加PPO训练、继续调整pulse频率，或按离线GT删除坏引用，都不能直接回应本轮暴露的全部问题。

本次仅归档与复核，未新建Stage-103或修改冻结代码。仍没有新的完整视频方法通过能力保护，整视频成绩继续以Stage-100为准，28组确认集保持封存。
