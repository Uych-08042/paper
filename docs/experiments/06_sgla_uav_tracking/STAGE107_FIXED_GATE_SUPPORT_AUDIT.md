# Stage-107：固定提交门控的训练支持与大错判审计

## 问题与本轮用途

Stage-105已经证明，一次普通历史与外观的共同提交能改变后继真实跟踪，并同时存在大收益与严重损伤。Stage-106用49维线上信息拟合提交门控，future整体未超过myopic、always_pair及同率对照；0304／556放过有害提交，1083拒绝有益提交，0176／251两头都漏救援。

下一步先区分两个问题：**模型在自己的训练样本上就没有学出区分，还是训练内能分、留出源组后失效？** 同时检查大错判对应的特征贡献、训练近邻和完整旧轨迹中的训练范围覆盖。结果用于决定是否补充代表性状态、修改状态表示或学习目标。

本轮读取Stage-106既有56模型、样本特征及80份曝光缓存。没有新模型、新优化、超参数搜索、图像、GPU推理、完整轨迹或确认评价，也不改变当前门控。计算固定矩阵上的分数分解，不更新系数。COMPLETE只表示审计完成，没有方法采用门槛。

## 1. 审核每个固定模型

从samples.npz及同行身份CSV重建该模型的训练支持，排除整个被留出源组的所有片段／种子／模式。核对输入指纹、训练源组／条数／上下文、fit-only加权均值／标准差／min/max、目标加权均值和截距。

固定标准化矩阵`Z`、权重`W`、目标`y`，验证封存系数满足：

```text
A = Z' W Z + 1.0 I
A beta = Z' W (y - intercept)
```

不重新拟合beta。归一化及分数核对固定`atol=1e-10, rtol=1e-9`，正规方程最大绝对残差除以`max(1,max(abs(rhs)))`须≤1e-9。这是浮点重放检查，不是学习效果通过门槛。旧模型不满足时停止，不能带着来源错误继续解释结果。

## 2. 训练内与留出组的表现

对每个固定模型分别计算`fit_resubstitution`和`held_out`，共112行；两头×两阶段的跨模型均值为4行。训练内是重用训练标签的回代成绩，28个fit集合高度重叠，不是28次独立确认。

误差及效用均以**共同有限且有实际提交变化的合法样本**为条件，重新按组→种子→模式→锚点归一化。不能直接与Stage-106按全部259锚点的宏均值比较；无变化样本计入原样本／逐状态清单，排除于这里的条件指标。

每个模型报告：

- 自身目标的MSE／MAE／R²，及固定训练截距预测的MSE基线。held_out基线也使用训练截距，不使用留出标签确定截距。R²分母是当前被描述集合的加权目标方差，方差0时留空。
- 自身目标正／负样本的放行比例；另列两头都按真实future正／负标签计算的放行比例。
- 相对keep的真实future效用、always效用、同上下文同率均匀选择的解析期望、可执行oracle效用及遗憾、提交率。

future与myopic目标不同，不以两头自身目标MSE直接判谁更好。真实后继效用列才使用相同future标签。训练内误差改善而留出误差恶化提示泛化／支持问题；两边都弱提示当前配方在现有输入上区分不足。两种现象都不唯一证明某个模型容量、特征或数据因素是原因。

### 特征贡献

对49维逐一记录原值、fit中心／尺度／范围、标准化值、系数及`z_j*beta_j`。验证截距加全部贡献等于未加资格掩码的线性分数。有资格时它等于原门控分数；无变化／不合法时原门控分数为0，不能把0误解为特征贡献或系数都为0。

这解释固定线性模型如何算出分数，不是改变某个特征后真实跟踪会改善的因果效应。完整25,382行留服务器；13例双头的1,274行随结果回传。

### 不同训练源组的近邻

只用该留出模型的fit-only标准差，在49维空间计算均方根距离。先在每个训练源组内找一个最近锚点，再取距离最小的5个不同源组；同组多个片段／种子／来源不能占满近邻。距离并列按源组名，组内并列按原样本顺序。

排名只接收特征、源组和固定尺度；**完成排名后**才附加训练邻居目标、真实future标签及身份。查询GT／角色不决定近邻；被查询源组不在训练支持。每个合法样本两头最多5组，共2,240行，重点例130行回传。近邻标签均值是离线描述，不变成新策略、标签插值模型或置信概率。

### 训练源组的线性贡献

对固定训练归一化与正规矩阵A，查询标准化向量z：

```text
h_i = w_i * (1 + z_i' A^(-1) z)
linear_score = sum_i h_i * y_i
```

验证`sum(h_i)=1`以及按训练源组汇总的目标贡献之和等于原线性分数。报告每组影响权重之和与目标贡献；允许负权重，不能当概率。该计算只解固定A上的投影，不优化或保存新beta。

分解固定了A、尺度与原有权重；**不是删除某个训练组并重新归一化／拟合的效果，也不是某个源视频导致实际失跟的因果占比**。逐状态`negative_influence_weight`是源组聚合权重中负值的和，不是所有逐锚点负权重的和。完整13,986行留服务器，重点例702行回传。
