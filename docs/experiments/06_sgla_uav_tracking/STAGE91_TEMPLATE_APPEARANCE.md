# Stage-91 首帧模板外观一致性诊断

Stage-90 的 Hann、速度和候选共识在 `0091` 同时支持一次会破坏恢复的切换。Stage-91 检验首帧目标外观能否提供独立于这些信号的判断依据。使用 Stage-89 冻结的 158 个同起点、同布局窗口。每个窗口仍只有原 PPO 框与预选 Hann 备选框两种写入。

## 外观信号

- **SGLA patch 相似度**。读取原生 SGLA 现有前向中、加入位置编码及融合前的模板和搜索 patch 特征。按图像坐标的框与 patch 面积交叠加权，分别池化首帧目标框与当前候选框，做 L2 归一化后取余弦相似度。模板不更新。分数不进入 SGLA 响应图或冻结 PPO。
- **RGB 颜色对照**。在同一真实像素区域上，对 R、G、B 各用八个固定桶。以归一化直方图的 Bhattacharyya 系数比较当前候选与首帧模板。这个对照检验较简单的颜色线索能解释多少。
- 模板框和候选框只使用裁剪中实际可见的区域。真实像素覆盖不足 50% 时该外观比较缺失，保持原 PPO。外观差为备选相似度减 PPO 框相似度，沿用 Stage-90 的正差切换条件。只使用首帧初始化框及当前预测信息。

## 评价

主读数是冲突组的后续 15 帧平均 IoU、16 帧低 IoU 比例与独有恢复。将 patch 和 RGB 与 Stage-90 的 Hann、速度、共识并列。排序 AUC 在两种外观都有效的共同子集上计算，正负实质差异各须来自至少三个源组。一次切换的配对指标保留全部窗口，按源组聚合。记录 `0091` 中原 PPO 独有恢复是否保留，也记录 `0147` 的备选独有恢复是否选中。独有恢复样本各一次，用于检验具体行为。

诊断重新执行每个窗口的四次原生搜索，逐项核对写入框、候选、裁剪、动作和预算与 Stage-89 一致，共 632 次搜索与 4,424 次骨干块调用。两项外观分数从现有前向和同一图像获得。后续 15 帧直接用 Stage-89 已有续跑结果。无训练、无新增续跑、确认集不参与。

## 服务器运行

同步代码和已归档的 Stage-89 结果包，激活 `sglatrack-test`，在仓库根目录执行。

```bash
bash tools/run_stage91_template_appearance.sh
```

默认读取 Stage-76、Stage-89 缓存和原始 checkpoint。原 Stage-89 使用 L20。若当前是 L40，仍执行同一逐窗口精确复现检查，出现任何差异即停止该次诊断。运行目录绑定 GPU UUID，换卡请使用新的 `STAGE91_ROOT`。完成后脚本打印结果 TXT 路径。
