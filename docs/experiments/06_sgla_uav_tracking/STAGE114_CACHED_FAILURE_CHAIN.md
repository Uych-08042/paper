## 2. 全量当前状态标签

评价标签使用当前GT，固定IoU≥0.5为好、IoU<0.2为低。GT无效时单列invalid_gt，排除于质量比例支持。q0指本条轨迹当前已经观测的q0输出，不等于另外运行的native整条轨迹。

| 标签 | 定义 |
|---|---|
| physical_nonq0 | 实际输出坐标与同状态q0不同，区别于仅候选索引不同 |
| harmful_q0 | q0≥0.5，但实际选择<0.2 |
| beneficial_q0 | q0<0.2，但实际选择≥0.5 |
| missed_good | 至少一个候选≥0.5，实际选择<0.5 |
| severe_miss | 至少一个候选≥0.5，实际选择<0.2 |
| no_good | 全部候选<0.5 |
| all_low | 全部候选<0.2；连续3帧另记持续供给不足起点 |

记录q0/实际/最佳IoU、搜索裁剪对GT的覆盖率、输出中心误差与宽高比、原始/Hann峰值、实际与q0评分差、可信写入资格位，以及生成均值/条件范围。资格位仍是原预测输入，不能称新增外观记忆模块。

所有轨迹都报告第一次物理非q0、第一次harmful_q0/severe_miss/all_low、第一次连续3帧all_low、第一次失败及第一次持续至少32帧的失败。32是固定诊断长度，不更改原失败事件定义；失败/恢复仍沿用仓库连续3低/连续3好。

逐轨迹比例先在视频内平均评分种子，再对视频等权，分all/historical/expanded；同时保留真实帧总数。physical_nonq0比例使用全部帧，其余质量比例使用有效GT帧；不能混用分母。

## 3. 共同历史前缀与单次提交影子

全部非native轨迹分别对照本视频native；generated_hann另对fixed_hann，generated_shared另对同种子fixed_shared。合计252个前缀对比（每视频9个）。

定位首次输出坐标分叉，核对直到该帧为止双方过去输出相同、q0父框及q0输出完全一致。下一帧才允许history_latest开始不同。记录分叉当帧双方实际IoU、共同q0/候选最佳、是否harmful_q0及首次q0裁剪不同帧。这让“相同过去上的第一次选择差异”与“已经不同的历史上的结果差异”可分开阅读。共享臂的生成/固定使用各自匹配训练评分器，前缀比较仍不是纯生成器效应。

每个统一选出的案例，另计算一次**只把当前实际提交改为当前已观测q0**的几何影子：沿用当前观测，重算替代的可信资格、下一帧生成输入/父框/裁剪，并与实际下一帧父框重建值核对。报告下一帧裁剪是否不同及父框最大绝对像素差。

影子只计算下一帧几何，没有替代下一帧图像观测、框输出、IoU或恢复轨迹。因此它只能证明这次提交足以改变后续搜索输入，不能证明改成q0就能避免失跟，也不能把当前q0替换算成新政策AUC。

## 4. 失败、恢复与训练输入支持

完整列出原轨迹全部147个失败事件，提供起点/确认/末尾/恢复及删失类型。固定前后16帧窗口内记录第一次harmful_q0、第一次连续3帧all_low及顺序。若窗口开始已经all_low，标left_censored；窗口内顺序只是描述，不能当唯一因果证据。

复现原102条参考恢复匹配，并在参考恢复帧附上候选质量、覆盖、预测范围和局部变化。所有未匹配恢复均进入案例表，不只选0304。参考是native或同种子fixed_shared，仍按原15帧匹配规则；两类参考可能重叠，不相加成独立事件数。

生成输入单列三个阶段：首个跟踪帧cold、2～4帧short_history、从第5帧开始from_frame5。记录生成器均值模型训练标准化后的输入最大绝对值/RMS，以及共享评分器标准化后的最大绝对值和实际±10裁剪比例。

用当前GT相对本条轨迹最新历史框的中心/对数宽高变化，计算其距冻结生成均值的误差与条件范围之比；四维均落在范围内才记range_contains_truth。它是误差范围在自身轨迹上的经验覆盖，不是新的在线条件，也不保证候选解码正确。

标准化大值不自动代表失配的唯一根因或校准过的OOD概率；名义90%校准范围也不能直接视为当前闭环分布上的90%保证。需要结合首次分叉和供给变化判断。没有读取图像，不能将峰值/框变化直接解释为遮挡、模糊或相似物干扰。
