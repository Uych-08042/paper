# Stage-152 灰度改选只更新搜索中心的整段闭环

Stage-151 在触发样本上发现，保留回归宽高可避免 0089／1159 换框后失去好候选，也能保留 0085／690 的恢复。后继 32 帧仅有 7 个完整起点。Stage-152 把这个规则放到 28 个完整开发视频中运行。 [Stage-151 结果](STAGE151_RESULTS_REVIEW.md)

## 四组同卡对照

| 分支 | 当帧报告的框 | 下一帧搜索父框 |
| --- | --- | --- |
| 原生 SGLA | Hann 原生框 | 原生框 |
| 回归 | Stage-143 留出回归框 | 回归框 |
| 完整灰度 | 灰度规则接受时报告备选框 | 使用当帧报告框的全部几何 |
| 只换搜索中心 | 灰度规则接受时报告备选框 | 采用当帧报告框中心、回归框宽高 |

两个灰度组在规则未触发时都用回归框作为输出和搜索父框。组间的同帧输出可在上一帧状态分叉后变化。只换中心组从第一处状态分叉开始使用自己的搜索结果续跑。四组都从第 0 帧真值框开始，每帧只调用一次原生 SGLA，预计共 112 条轨迹、116,188 次跟踪搜索。核验基线和首次改选前的输出，并在原生轨迹上影子计算 Stage-149 的灰度规则。与 Stage-121 运行身份相同时，影子需复现 Stage-149 所有 4,514 个采样原生选择。

触发沿用 Stage-149 第一次确定的 0.025 灰度接受门槛、回归分差上限 0.15、框重叠上限 0.40，及首帧灰度和近期颜色描述子都可用的资格条件。近期描述子仅从各组自己的已处理帧取得。冻结 SGLA 和按源组留出的回归评分器。

## 评价

优先看只换中心相对完整灰度的 AUC 配对差，再与回归和原生 SGLA 对比。报告视频等权成功率 AUC、视频重采样区间、低 IoU 比例、最长失跟比例、未恢复事件，以及原生或回归稳定视频的新增失跟。失跟按连续三帧 IoU < 0.20 定义，恢复按连续三帧 IoU ≥ 0.50 定义。改选表同时保存当帧回归框、报告框及搜索父框的离线 IoU，以便追溯触发。开发视频已用于前序设计。

## 执行

同步代码，在训练服务器仓库根目录的 `sglatrack-test` 环境运行。需要原 SGLA 权重、VisDrone-SOT 和 Stage-76、89、93、121、143、149、151 完整产物。首次可用 L20 或 L40，四组同卡重跑。运行中断后同目录保持同一 GPU 运行身份。

```bash
mkdir -p output/stage152
nohup bash tools/run_stage152_center_closed_loop.sh > output/stage152/run_stage152.log 2>&1 < /dev/null &
```

默认输出到 `output/stage152/center_closed_loop_v1`，完成后回传其中的 `stage152_results_*.txt`。
