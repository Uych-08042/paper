本轮检验目标条件表征适配、任务质量选层、定位质量读出的独立贡献及组合效果。修改发生在 SGLA 内部，保留原生首帧初始化、单搜索裁剪、六个共享前缀块、一个独立候选块、CENTER 几何预测和状态反馈。

Stage-192 在跨开发源组的 16 个失跟窗中观察到 10 个有框漏选。Stage-193 的第二峰改选只保留两个挽救，并在 36 稳定窗新增 7 次失跟。原生相似性标签也没有直接监督实际框质量。这些证据支持研究任务对齐，尚未证明引入时序记忆有效。Stage-48／52 的头训练、Stage-167／170 的路由负结果需作为历史边界。

本轮首先检验目标条件，不加入历史记忆、固定时长冷却、多搜索或 PPO。时间信息是否有必要，须由后续正确历史与打乱历史的匹配对照验证。依据及文献见[全阶段研究综述](../../research/SGLA_EXPERIMENT_SYNTHESIS_AND_METHOD_BASIS_2026-11-25.md)。

## 三个因素

### A 共享前缀后的目标条件残差

设 L6 token 为 F，通道数 D 直接取原骨干配置。首帧模板对应 token 在当前共享前缀中已经与搜索 token 交互。其均值 c 经过一个 D→2D 的线性映射得到 s、b。

F' = F + tanh(s) × LayerNorm(F) + b。

映射零初始化，初始输出与原生 F 完全一致。选择 L6 接入是因为它是所有独立候选块的共享输入边界，不代表已经证明该位置最优。这里不增加任意隐藏维数、低秩参数或记忆长度。

参数匹配的 current 对照以当前搜索 token 均值替代模板 token 均值，结构、初始化、参数数量、目标、更新和样本完全相同。它区分目标条件与普通特征适配的收益。该对照不能独自证明目标身份关联或时序能力。

### R 分支质量路由

分别计算模板和搜索 token 的逐通道均值、标准差，拼接为 4D 输入。线性映射 4D→6 后 Sigmoid 输出六个分支的质量预测。维数由原骨干的通道数和四项全通道统计导出，没有使用任意 16 维投影。

训练目标是同状态、各分支在本组评分机制下实际选出的预测框 IoU，以 MSE 监督。质量目标与推理动作一致。MSE 的统计含义是条件均值估计，不保证排序或闭环最优。推理只执行被选中的一个独立块。

原 MLP 为保留原生执行和调用审计仍会运行，它的输出在 R 开启时由新路由替代。新路由的计算计入实际延迟，因此本轮不主张节省计算。

### Q CENTER 定位质量残差

在 CENTER 输入的搜索特征图上用 D→1 的 1×1 卷积产生响应 logit 残差。初始残差为零，并消除 sigmoid/logit 数值往返误差，使初始响应精确等于原响应。

监督标签为每个实际网格框的 IoU。标签依次应用 CENTER 格点解码、原生浮点父框回映、图像裁边、margin=10 与评估器的预测 xywh 取整。真值保持原浮点坐标。标签 stop-gradient。

推理保持原 Hann 和 CENTER 几何图，由新分数决定选择位置。原生几何与响应卷积权重均冻结。该方法检验能否改善有框漏选，不直接学习长期后效。

## 训练预算与范围

使用 Stage-170 的 28 个开发源组和 Stage-188 的 10 个补充开发源组，复用 Stage-192 的核验装载入口。按源组固定两折，每折 19 个 fit、19 个 held。确认集的 28 个源组继续封存。开发源组曾反复用于设计，本轮 OOF 仍是开发证据。

每个视频在全部跟踪帧上均匀选最多 48 帧，保留出裁剪的状态。采样不使用失跟点、IoU 高低或未来事件。输入为该状态原生父框执行下的 L6 token。训练不会读取 held 源组的特征或标签进行更新、归一化、提前停止或最佳固定层选择。

沿用 Stage-48／51 的每视频 48 状态、256 更新、学习率 1e-5、AdamW、weight decay=1e-4、梯度上限1和种子2132／2133。batch=4 对应既有每步两对双视图的4个监督视图机会，本轮为4个独立均匀状态。全部是预先声明的 pilot 预算，未声称最优。

每折每种子各组读取完全相同的组／状态抽样序列。每步所有组运行六个独立候选块和六次原生头前向，固定六分支监督机会。A 使用六分支平均的原定位目标 2GIoU+5L1+focal，并在 GT 热图峰处回归。R、Q 使用 detach 特征和 detach 标签，只有各自参数接收对应 MSE 梯度，避免通过移动标签降低损失。各模块分别裁剪梯度，避免新增损失缩放另一模块的梯度。

原生网络参数和 BN buffers 始终冻结。A 的训练梯度会经过冻结候选块和预测头返回新残差参数。训练范围属于对共享前缀输出的参数高效适配，没有微调 L1～L12 的原始矩阵，也没有实现顺序动态深度。

相同样本和更新数不能使反向计算成本相等。scope 表分别报告训练参数、有效样本、候选执行例数、耗时、梯度范围、draw 哈希及冻结检查。不同计算预算的比较需按实际成本解读。

## 评价与预先声明的比较

正式运行从各视频首帧 GT 初始化开始，完整使用本组自身预测，不进行指定事件的一次替换。每个视频3个冻结控制和9组×2种子，共21条轨迹。38个视频共798条完整轨迹。每个 held 视频只使用不包含该源组的模型。

同时在 held 的均匀原生父框状态上做六分支读出诊断，真值只在预测之后附加。它用于区分分支供给与池内选择，并非完整轨迹结果。输出被选框IoU、最佳分支IoU、选中网格的最佳IoU、全网格最佳IoU、分支regret和有框漏选数。

主比较为 a1_r1_q1 对 current_a1_r1_q1，检验参数和训练匹配后目标条件是否有增量。其他比较包括各组对原生、fit最佳固定层、单模块和组合。种子先在视频内平均，再对源组做配对bootstrap。多重比较区间为名义区间，属于探索性结果，状态固定为 REVIEW，不产生自动采用或 SOTA 判断。

报告 AUC、平均IoU、低IoU比例、最长失败、未恢复事件、新增稳定视频失败、原生恢复时刻的三帧恢复保留、原生好帧上的精度损失及延迟。恢复指标是特定时刻的保留，需结合完整事件表理解，不等于证明恢复能力普遍消失。延迟包含观察器与读图开销，不作为部署速度基准。

解释规则预先固定。

- current 对照相当或更好时，不能主张目标条件机制有效。
- 最佳固定层相当或更好时，不能以分支使用多样性主张自适应价值。
- 固定状态质量改善但完整视频退化时，优先分析自身状态分布和恢复损失，不继续宣称模块已有效。
- 三模块组合未优于单项时，不能声称必须联合三个模块。
- 模型未充分拟合标签时，记录为当前优化预算限制，不能据此否定整个理论方向。

下一轮依据实际贡献选择研究方向。先建立模块增量，再考虑历史建模、学习策略状态聚合、真实顺序动态深度和独立确认，避免一次加入所有结构。
