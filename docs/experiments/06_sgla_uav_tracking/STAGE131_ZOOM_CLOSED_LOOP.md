# Stage-131 保留 q3 的单槽局部放大全视频评价

**正式全视频评价已完成。** Stage-130 的保留 q3＋第一高响应位置条件新增 5 个有好候选的起点，原 13 个好候选点保留；最终好选框从 3 增至 5，两处新增均在 0080。Stage-131 把这个固定规则接入完整预测反馈，检验局部改善能否转化为整段跟踪收益。 [Stage-131 结果](STAGE131_RESULTS_REVIEW.md) · [Stage-130 结果](STAGE130_RESULTS_REVIEW.md)

## 同视频配对

沿用 Stage-121 的 28 段开发视频，给定首帧真实框和原始首帧模板。三种多搜索条件各用原冻结的两种子模型。每条轨迹从首帧起独立运行到最后一帧，后续搜索仅使用自己的预测历史、当前图像及原始冻结模块。

| 条件 | 搜索规则 |
| --- | --- |
| 原生 SGLA | 单搜索，提供整段跟踪基线和可靠帧参照 |
| Stage-121 | 原四槽候选、原备用请求规则 |
| 缩边 | Stage-121 规则加上 Stage-128 的冗余补边缩放 |
| 单槽放大 | 同一缩边规则，实际换入备用搜索且存在超限裁剪时，保留 q0、q3 和广域槽，用第一高响应位置替换一个其余槽位 |

广域槽与 q0 或 q3 重合时额外保留 q1。局部尺度和筛选沿用 Stage-129 规则。放大只在实际启用备用搜索且有超限裁剪的状态尝试，贴合 Stage-130 的测试范围。找不到合格局部位置时，继续当帧缩边布局。广域前向的结果复用，本帧最多四次实际搜索。

主指标为单槽放大对缩边的整段 success AUC 差。每视频先平均种子，再对视频等权，给出 95% 名义视频 bootstrap 区间和两种子分别的均值差。并列低 IoU 帧比例、最长失跟比例、SGLA 可靠帧 AUC、好候选比例、好选框比例、新增失跟和丢失匹配恢复。首次放大之前要求两条轨迹逐帧一致，首次放大当帧审核三个保留槽位完全一致。后续状态分叉是本实验测量的效应之一。本阶段使用反复使用过的开发组，确认集不运行。

累计评价 196 条轨迹。同运行身份复用 Stage-121 的 84 条原生和备用对照，只新跑缩边与放大共 112 条，新增搜索上限 464,752 次。换到另一张受支持的 L20／L40 或不同 GPU UUID 时，四组都在当前卡计算，上限 726,175 次。冻结的 SGLA 配置、权重、软件和原评分器保持同一身份。结果文件会分别报告实际物理调用和逻辑上限。

开发判据采用已有的 +0.5 AUC 实用门槛，要求视频区间下界为正、两种子均为正，且相对缩边组无新增稳定视频失跟或丢失匹配恢复。原生与 Stage-121 的保护差一并报告。

## 后台运行

同步代码后，在服务器仓库根目录运行。

```bash
mkdir -p output/stage131
nohup bash tools/run_stage131_zoom_closed_loop.sh \
  >> output/stage131/run.log 2>&1 < /dev/null &
```

日志会报告每段进度和最终 `stage131_results_*.txt` 路径。使用 `STAGE131_GPU` 选择逻辑 GPU，通过 `STAGE131_ROOT` 另开输出位置。相同输出目录的中断续跑复用已完成的轨迹和回执；换卡续跑应使用新输出位置。用 `--pack-only` 重新校验并打包已完成结果。
