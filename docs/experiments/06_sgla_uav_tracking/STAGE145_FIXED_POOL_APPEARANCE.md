# Stage-145 同候选池的外观证据诊断

Stage-144 的线性成对排序仅在 18 个全网格独有好框机会中选中 1 个，难例加权损伤了稳定窗口。Stage-145 检查固定候选中，外观相似度能否区分现有评分混淆的好框和错框。 [Stage-144 结果](STAGE144_RESULTS_REVIEW.md)

## 冻结输入与样本

- 使用 Stage-142 两套候选池及 Stage-144 的逐帧结果作为参照。每个入选状态逐项复核候选格点、顺序和原有评分选择。所有方法使用已有解码框和同一裁剪内的有效图像区域。
- 覆盖 28 个开发视频，包含 281 个原生 IoU < 0.20 且全网格存在好框的帧、19 个原生失跟起点以及另列的 240 个回放状态。另从每视频均匀取最多 32 个状态，从其原生稳定窗口均匀取最多 4 个完整的 32 帧窗口。重叠帧去重。`native_sample` 是这个诊断样本。
- 复用 Stage-120 的八箱 RGB 直方图和 16×16 灰度归一化相关性。候选框与原裁剪有效区域相交，至少保留原框面积的一半时计算外观。首帧参考使用任务给定的框。近期参考只选当前帧之前 12 帧内、间隔至少 3 帧的最多 3 个记录预测。原生 Hann 框需与两池的原始响应首选一致，且相对当时父框的中心移动不超过父框几何平均边长的 0.75 倍。回放只读取同一分支中已有的较早预测。近期分数对有效参考的相似度取平均。

## 读数

- 失跟对由池内真值最佳好框和 Stage-143 评分选中的错框组成，要求原生 IoU < 0.20。稳定对由原生好框和原始响应选中的错框组成。好框阈值为 IoU ≥ 0.50，真值用于诊断分组和确定配对方向。
- 报告外观分数将好框排在错框之前的次数、并列次数、有效配对数及按源组等权的差值。响应与原评分对照均在相同的有效配对上计算。失跟对按原评分误选构造，稳定对按原始响应误选构造，这两个条件化集合用于机制诊断。
- 另报告四种外观分数各自直接选框的固定状态读数。该分数在候选池内全部有效才进行比较，否则沿用 Stage-143 质量评分。另报完整候选池可打分的状态数、原生稳定窗口连续低 IoU，以及 0089／1159、1165、1166。

仅 CPU 读取冻结帧并计算外观，不训练评分器、不新增 SGLA 搜索或状态写回。外观证据的适用性按有效率和成对结果解释，整段 AUC 与恢复需要闭环验证。
