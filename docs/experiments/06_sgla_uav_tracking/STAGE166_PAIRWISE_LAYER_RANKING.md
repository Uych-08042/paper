# Stage-166 用同帧层间偏好监督选层

Stage-165 的退化调整分数在实际后 32 帧 IoU 相差至少 1 个点的 338 对非原生候选层中排对 50.3%。重提议并重排起点后的平均 IoU 略低于四帧收益对照。Stage-166 改为直接监督同帧层间次序。

## 对照设计

所有方法复用 Stage-159 的 328 个开发起点、28 个视频、两折源组划分和各层后 32 帧的分支结果。执行层评价固定四帧对照已选的 68 个起点，两折分别为 64 和 4 个；其余起点执行原生层。比较四帧对照、Stage-165 同起点重提议、仅使用层编号的成对排序，以及使用 16 维 L6 投影和 8 个历史统计的成对排序。

训练使用原有可换层起点，每点只比较非原生层。如果只有一个候选引入持续低 IoU 或丢失原生恢复，则优先另一个候选。如果两者都安全且后 32 帧平均 IoU 至少相差 0.01，则优先 IoU 更高的层。其他层对不进入拟合。用层分数之差拟合带正则化的逻辑损失，按源组平均权重，再在组内按起点和层对分配。预测只使用训练源组拟合的系数和特征归一化参数。

排序准确率在原有可换层起点评价，报告合并层对准确率和按视频等权的准确率。两套评价分别使用 IoU 层对和训练定义的安全优先层对。跟踪指标用固定 68 个起点实际选中的层计算。

## 缓存结果

只使用层编号的排序器已在本地完成两折拟合和留出评价。对 IoU 至少相差 1 个点的 338 个层对，合并准确率为 50.0%，按有层对的视频平均为 52.8%，Stage-165 的对应数值为 50.3% 和 47.4%。层编号组整体后 32 帧 IoU 为 0.605358，比四帧对照低 0.009 个点；剔除 0176 后高 0.014 个点。0176 的恢复保留，切换层由 L7 变为 L12。此处的结果来自层编号对照。

## 正式运行

同步代码后在服务器仓库根目录执行。CPU 读取 Stage-159 特征缓存及 Stage-165 分数，无需 GPU 推理。脚本保留总体进度条，并将结果表打包为 `stage166_results_*.txt`。

```bash
mkdir -p output/stage166
nohup bash tools/run_stage166_pairwise_layers.sh > output/stage166/run_stage166.log 2>&1 < /dev/null &
tail -f output/stage166/run_stage166.log
```

比较带状态排序器在总体和剔除 0176 后的按视频平均排序准确率，要求高于归档收益、原风险调整分数和仅层编号对照。完整视频验证还要求后 32 帧 IoU 在两种统计范围均高于四帧收益对照，保留已有恢复，并且无新增持续低 IoU 或丢失原生恢复。
