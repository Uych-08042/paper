# Stage-143 固定候选池的定位质量评分

Stage-142 在严重低 IoU 且网格有好框的 281 帧中，把池内有好框的帧数从 162 提到 179。Stage-143 检验好框进池后能否被选中，以及改选是否损伤原生稳定状态。 [Stage-142 结果](STAGE142_RESULTS_REVIEW.md)

## 输入与对照

- 主评估用原生 SGLA 的 28 个开发视频、29,047 个缓存状态。19 个原生失跟起点单列。Stage-139 的 240 个分支回放帧单列，并检查 0089 的 1165 和 1166 帧。
- 原裁剪、响应、解码及 Stage-142 局部峰池和全网格池固定。每帧两池保留同一个原生首选，数量相等且最多 8 框。同视频各组的候选计数以及 259 条有逐帧记录的格点顺序均与 Stage-142 核对。
- 每个池比较原生 Hann 首选、池内原始响应最大、共享质量评分最大。真值池内最优只用于估计当前候选池的上限。分数相同时沿候选池既定顺序选取。
- 质量评分使用 9 维可观测信息，包括格点原始响应、Hann 响应、各自相对峰值比例、3×3 原始响应均值，以及候选相对上一帧父框的横纵位移和宽高变化。固定岭系数 0.03，用真值 IoU 训练。两个池用同一个模型，各状态两池的并集按格点去重后用于拟合。每个源组等权，源组内各有效帧等权，帧内有效候选等权。
- 按视频源组逐组留出，标准化和拟合均使用其他 27 个源组的原生状态。所有分支回放仅用于评估，使用其所对应源组的留出模型。选框时只读当前响应和父框。

## 读数

两池同时有好框的低 IoU 帧用于比较选框能力。全网格池独有好框的帧用于判断新增供给是否被实际选中。主轨迹另报所有帧、原生低 IoU 帧、网格有好框的严重低 IoU 帧、各池有好框的严重低 IoU 帧，以及失跟起点。好框阈值为 IoU ≥ 0.50，严重低 IoU 为 IoU < 0.20。按源组等权报告平均 IoU、好框率和配对 bootstrap 区间，逐帧计数单列。

稳定性对照使用从跟踪第 1 帧对齐、互不重叠的 32 帧窗口，要求原生每帧 IoU ≥ 0.50。报告改选后掉到 0.50 以下的帧、掉到 0.20 以下的帧，以及出现连续至少 3 帧低于 0.20 的窗口。稳定窗口和失跟起点均在评估时用真值标记。结果是开发集固定状态诊断，整段跟踪 AUC、恢复和失跟传播仍需闭环验证。
