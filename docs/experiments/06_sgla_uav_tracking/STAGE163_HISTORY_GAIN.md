# Stage-163 收益预测的历史特征消融

Stage-162 用最多 16 帧历史和趋势特征预测退化，使 0176 第 163 帧的 L7 候选从第 113 位升到第 62 位，进入第一折的前 64。28 个开发视频的后 32 帧平均 IoU 相比四帧退化预测提高 0.168 个点。剔除 0176 后，差值为 −0.011 个点。

Stage-163 复用 Stage-162 已核对的退化预测、Stage-159 提议层和原生层。两折各换层 64、4 次。对照继续使用原来的 24 维收益输入，包括 16 维 L6 投影和 8 个四帧统计。实验组改用 27 维输入，同一 L6 投影拼接最多 16 帧的 8 个基本统计和 3 个趋势统计。两组按预测收益减去同一个退化量排序，候选仍限于原提议层和原生层。新收益模型用同样的岭回归和源组加权，标签为每层相对原生层的后 32 帧 IoU 差值。每折只用训练源组拟合。实验比较的是长窗口与趋势统计的组合。

## 服务器运行

在仓库根目录启动。脚本从 Stage-121 原生轨迹和 Stage-159 逐点缓存重建历史，绑定 Stage-162 正式消融的已签名结果。使用总体进度条，默认每 15 秒更新。完成后在结果目录生成包含判定、配对、两折配额、关键案例和逐点排名的文本报告。

```bash
mkdir -p output/stage163
nohup bash tools/run_stage163_history_gain.sh > output/stage163/run_stage163.log 2>&1 < /dev/null &
tail -f output/stage163/run_stage163.log
```

## 判定

检查 0176 第 163 帧的恢复和对照已有的其他恢复、相对原生的新增持续低 IoU 和丢失恢复、相对对照的总体 IoU 增益，以及剔除 0176 后的增益。五项通过后安排在线阈值和完整轨迹对照。若剔除 0176 后收益仍为零或负，下一轮验证 L6 的全局投影是否掩盖模板对应的局部空间差异，并用相同候选和配额控制比较。Stage-163 的结果限于 VisDrone-SOT 开发窗口。
