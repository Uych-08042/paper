# Stage-186 搜索裁剪取整与移动方向对照

Stage-185 的 0091 在保持 67 像素裁剪边长时，左上角的微小整数变化改变了 L9 的 Hann 选峰。Stage-186 检验预测图的变化是否依赖实际取整窗口变化，并比较观测方向与同像素幅度反方向的后效。

## 对照构造

复用 Stage-185 的 19 个变化点和 8 个稳定窗口。在每个写回点的第一后续帧固定模板、L9 和基准写回框宽高。以只改映射分支为当前裁剪，使用只换中心分支的原始浮点位移定义对照。

| 处理 | 裁剪构造 |
| --- | --- |
| 当前 | 保持基准中心 |
| 同一取整窗口 | 沿观测方向移到窗口首次取整变化之前，采用基准与边界之间的中点。若观测位移本来就在同一窗口，保留实际位移 |
| 仅水平／仅垂直 | 各自保留观测位移的一个分量 |
| 实际方向 | 执行 Stage-185 的中心位移 |
| 等幅反向中心 | 在浮点坐标中反转中心位移 |
| 等幅反向像素 | 反转取整矩形的实际二维位移，保证整数位移幅度相同 |

另保留原生当前裁剪分支以评价稳定性和事件伤害。0348 第 361 帧保留 Stage-185 的只换宽高分支作为尺寸对照，单列观察。

## 读出和续跑

- 报告实际取整裁剪、中心到目标的距离、目标覆盖、Hann 选峰、三张预测图的最大差异、常规输出与全网格最佳 IoU。同一取整窗口的预测图须复现。同尺寸组再统一回映到基准父框中心，测新裁剪对网络预测的作用，并报告水平与垂直位移的当帧交互。
- 写回各组实际输出并恢复原生路由，后效包括第一个后续帧，最多 128 帧。同环境复核 Stage-185 已观测的 L9 分支，并复用在相同帧得到完全相同写回框的续跑。其他支持的运行环境在同卡重做。结果分报实际跨边界、完整 128 帧和稳定样本，同时列出观测方向和等幅反向像素的逐源差值。全部基于已有开发事件。
