## 3. 训练覆盖：每个视频最多一个近邻

距离使用**原训练归一化后的未截断13维特征**的RMS欧氏距离。这样不会因clip±10把相距很远的样本挤成一样。归一化只来自原训练例，距离、排序和tie-break不读取任何IoU、后继收益、角色或门控分数。

对每个待评点，在该头的96例中为每个训练源组选一个最近点，平局按UID排序；六个训练组各保留一个，全部输出。局部摘要固定取最近3个不同源组。不会让同视频的多个相邻帧或两个种子重复充当三票。

为形成训练内距离参照，对每个训练例排除其**整个源视频组**，再从剩余5组中各找最近点，取最近3组平均距离，汇总96例的95%经验分位数。待评点的三组平均距离超过该参照时，标记distance_beyond_reference，同时给出连续距离、差值、最大标准化幅度与门控clip比例。

这不是统计覆盖保证或部署拒绝规则。训练参照搜索库有5组，而待评搜索库有6组；数据也非独立同分布，不能把95%经验分位解释成待评覆盖率95%。训练常数维采用原模型scale=1，其距离含义也受该规定影响。合成测试组较少时，k=min(3,训练组数−1)，正式6训练组时固定k=3。

近邻身份确定后才附加当前／后继标签，报告局部future均值、范围、正负混合和材料性正负混合。材料性阈值固定±0.1，源自Stage-118已经使用的描述尺度，不参与选择或参数优化。相近点收益相反是当前表示下的经验冲突，不能证明真实目标身份或更长时间信息无法区分。

另报每个头96训练例中的大正／大负后继数、支持源组数、严格当帧救援数和训练clip比例。压力案例没有进入训练；普通uniform中稀有情形缺失应如实保留，不能按评价标签补入原训练表。

## 4. 分数为什么被推成正或负

对778点全部输出两套固定代数分解，不只手挑失败视频。

**特征分解：** 标准化并clip后的13维查询值与β逐项相乘，另列截距，共14项；其和必须等于已保存的myopic／future分数。数值最大／最小项及绝对贡献和进入逐点摘要，完整项保留服务器。

**训练源组分解：** 固定原A、Z、W和归一化，计算查询核权重 `hᵀ = z_queryᵀ A⁻¹ ZᵀW`，再将 `h_i·y_i` 按6个训练源组相加。两目标各组贡献之和必须等于对应冻结分数，未惩罚截距还要求核权重和为1。报告每组有符号核权重和、myopic贡献和future贡献。

核权重可以为负，训练组贡献与特征贡献也可能相互抵消。它们是在**固定归一化和正规矩阵下**的精确恒等式，不是删除某组后重训的效果，不是唯一的因果归因，也不能把某项为负解释成现实环境因素导致失跟。
