# Stage-184 固定尺寸和层的搜索中心分解

Stage-183 发现，只恢复搜索中心可使多个诊断状态重新输出好框。本轮检验这项变化有多少来自回映坐标，有多少来自重新裁剪后预测图发生变化，并测两者的交互。

## 对照

在同一帧、同一模板、同一层和同一裁剪尺寸下，交叉搭配 CENTER 的响应、宽高、偏移图与浮点父框中心。四组使用同一 Hann 窗。

| 组别 | CENTER 图来自 | 解码中心来自 |
| --- | --- | --- |
| 原生裁剪 | 当前裁剪 | 当前父框 |
| 只改映射 | 当前裁剪 | 较早父框 |
| 只换预测图 | 以较早中心重新裁剪 | 当前父框 |
| 完整中心修正 | 以较早中心重新裁剪 | 较早父框 |

较早中心用 Stage-183 固定的原生预测父框。稳定候选来自 Stage-182 的低波动对照，要求起点 IoU 至少为 0.5、128 帧后效标注有效且原生没有失跟。在稳定对照中，较早中心取当前父框之前一次的原生预测。真值用于诊断取样和评价。

## 评估

- 复用 Stage-183 的 19 个好框供给变化后状态。L9 为主要对照层，L7–L12 分层记录。在各状态核对坐标映射分辨率和真实解码，记录 Hann 峰位置、稠密最佳 IoU 和常规输出 IoU。
- 四组的当帧交互项等于完整修正结果减去两项单独处理结果，再加回基准值。续跑同样计算交互，并逐层与同层当前裁剪的轨迹比较。失跟状态续跑六层，稳定窗口续跑 L9。继续使用原生路由至多 128 帧。结果按源组汇总，同时给出剔除贡献最大源组的结果、受保护挽救和事件伤害。
- 完整修正具有直接的裁剪与解码对应关系，两组交叉处理是离线机制探针。运行环境与 Stage-183 一致时，复用两种裁剪的原始预测图和起始写回框完全相同的续跑。环境改变时，同卡重算两种裁剪及所有续跑。
- 开发点和此前未扫描事件分别报告。只有一种单独处理在不同源组保留完整修正的收益，并且稳定窗口没有新增伤害时，才有依据把这一机制带入后续独立验证。

```bash
mkdir -p output/stage184

```
