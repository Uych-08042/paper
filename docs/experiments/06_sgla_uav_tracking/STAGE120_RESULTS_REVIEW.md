# Stage-120：训练支持与外观信息的提交消融结果

复核日期：2026-11-16（Asia/Hong_Kong）。

**原训练支持下，加入轻量外观信息优于旧后继收益头，也优于外观打乱控制，提供了值得继续检验的表示增量线索；但“扩展支持＋外观”的预定主比较区间仍跨零，而且该组合在旧8个严格救援起点全部选择q0，救援保护失败。** 不能将本轮概括为外观完全无效，也不能宣布新的提交规则已经有效。

本轮是固定起点上的CPU学习与条件后继评价：使用已测量的一次q0动作分支，随后31帧恢复原冻结生成／共享评分策略。下文IoU均为0～1的条件后继均值，**不是完整视频AUC，也不是持续部署新门控的轨迹成绩**。最新完整自身轨迹评价仍是Stage-113。

## 执行范围与处理含义

状态 `COMPLETE_SUPPORT_APPEARANCE_COMMIT_FACTORIAL`。778个去重点、791个研究membership、56个种子上下文：普通均匀448点、普通分层309点、交集13，另有旧压力34点。新增168个CPU模型（140岭头＋28常数），复用28旧岭头与28旧常数，保存28个新模型包。外观账本1,484次RGB解码；SGLA权重更新、GPU搜索／块调用、新完整轨迹及确认推理均0。旧基线预测误差0，28确认源组继续封存。

每个待评源组只允许同一上游provider-held7中的另外6组训练，待评视频的普通、分层、压力、两个种子全部排除。原支持是96个均匀例；扩展支持加其他允许视频的旧压力例，实际每头100～107例，其中压力4～11例、总权重1/6～1/3。部分头仍无严格救援训练例（0～4例）。

扩展处理同时改变支持和固定权重：有压力的上下文，普通／压力池各占一半。**它检验的是“加旧压力样本＋重加权”的整体，不能只归因样本数，也不代表线上事件频率。** 旧压力由GT条件筛出，且全部开发源组已用于设计；源组隔离不使它成为新确认集。

原输入13维；外观头37维，增加首帧与最近可信预测参考的RGB直方图／灰度NCC匹配、覆盖率、有效位及参考年龄等24维。近期参考严格早于当前帧、窗口30帧；722/778点有近期参考，56点缺失，全部点保留。两候选的首帧匹配有效位均为1，近期有效位与参考存在位在此次数据中一致。

外观是**内容＋覆盖／缺失／年龄这一整组信息**，不是已验证的身份嵌入。打乱控制在拟合视频内联合置换24维，保留训练例、权重、容量和原始真实输入得到的归一化，评价用真实外观；实际向量值改变比例，uniform为86.46%～97.92%，expanded为89.72%～99.03%。它是有用的负控制，仍保留视频静态信息，不能唯一证明身份匹配的因果贡献。

## 接续判断

可以继续发展的线索是**原支持下增加当前候选与参考的可观测信息**，而非直接采用本轮扩展组合。后续最需要区分：收益来自图像内容还是覆盖／缺失／参考年龄，以及必要救援为何仍被接管；同时保持普通均匀、分层、旧救援和同率控制分别评价。扩展压力与重加权不能作为已经有效的组件直接继承。

下一轮若检验外观内容贡献，应把原13维、仅覆盖／有效位／年龄、再加真实匹配内容及相应打乱控制分开，保留待评整视频标签隔离；不能靠挑此次有利种子、改阈值或只展示均匀结果完成验证。这是根据本轮结果提出的后续消融方向，尚未实施或固定Stage-121。

当前没有可靠的新提交规则、完整自身轨迹增益或稳定／恢复保护通过。Stage-113生成共享完整AUC53.5418、对固定共享−10.5890和保护失败的事实仍有效，不能被这次局部表示增量替换。本次只做结果归档复核，Stage-1～120实验Python保持冻结，未启动Stage-121；未自动commit/push。
