# Stage-88 单布局写入信号诊断

Stage-87 的既有动作对中，按后续 15 帧平均 IoU 相差至少 0.05 计，固定布局高位移组有 2 个备选明显较差、0 个明显较好，中点布局高位移组有 3 个备选明显较好、0 个明显较差。低位移组无达到幅度的对照。Stage-88 补充同一固定布局内的备选分支，使候选和信号可由一次候选集直接构造。现有证据的支持数不足以拟合分类器。

## 同布局动作配对

沿用 Stage-86 的 144 个冻结窗口。两组使用同一套固定布局、同一帧四个候选和同一历史。PPO 组写入原选框。备选组写入余下不同框中 Hann 加权响应峰最高的框。同分按原槽位顺序，精确重复框用原 PPO 的规范槽位规则。没有不同框时保留原选择，计入总体分母。每个窗口只改变首帧写入，后续 15 帧采用同一冻结 PPO 和原固定布局。若备选写入框与 Stage-87 任一已验证分支完全一致，则复用后续轨迹。

备选框和三项信号只使用该帧固定布局的候选及预测历史。信号为正表示更支持备选框。

| 信号 | 备选与原选框的比较 |
|---|---|
| Hann 响应 | 比较加权峰值 |
| 速度一致性 | 比较与最近两帧框中心匀速外推位置的距离 |
| 候选共识 | 比较与去重候选中心的坐标中位数的距离 |

每个信号单独评估，值大于零时改写备选，其余情况保留原选框。总是写入备选作为简单对照。主要指标是首帧之后 15 帧的平均 IoU 差和 16 帧低 IoU 比例差。后续平均 IoU 增减至少 0.05 定义为有实质收益或损失。另报有实质收益或损失时的切换计数，以及起点 IoU < 0.2 且只有 PPO 分支能连续三帧达到 IoU ≥ 0.5 时，被切换规则丢掉的次数。两类实质差异分别覆盖至少 3 个源组时才报告排序 AUC。窗口和种子在视频内平均，配对区间按视频重采样。

这些是冻结起点的短窗对照。切换规则每个窗口最多作用一次，闭环持续执行仍需要后续验证。本轮无训练，确认集不参与。所有帧均由原生 SGLA 执行四候选搜索。新分支需先精确复现固定布局首帧，随后补跑 15 帧，每支合计 64 次新增搜索，最多 9,216 次。重复框和已验证轨迹复用缓存。

## 服务器运行

激活 `sglatrack-test` 后在仓库根目录执行。

```bash
bash tools/run_stage88_single_layout.sh
```

默认读取 Stage-76、86、87 的原运行目录。传入 `--plan-only` 可在 CPU 上先统计需要补跑的分支。若需补跑，GPU 型号和软件须与 Stage-86 缓存相同，默认是 L20。Stage-88 首次 GPU 执行绑定卡的 UUID。若只有 L40，需使用已在 L40 重建且配套的 Stage-86、87 缓存，并另设 `STAGE88_ROOT`。完成后脚本打印结果 TXT 的路径。
