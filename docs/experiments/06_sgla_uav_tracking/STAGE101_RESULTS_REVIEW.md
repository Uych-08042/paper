# Stage-101 全触发匹配回放结果

已完成1,834个实际触发状态和61个固定起点的122条短分支。跳过一次尺寸调整的当帧收益与损伤几乎相抵；0307的一处恢复附近分支明显改善，但0304、0169和0076的关键损伤没有消除。本轮缩小了问题范围，尚未形成新的可采用方法。 [固定协议](STAGE101_MATCHED_TRIGGER_REPLAY.md) · [原始结果](results/stage101_results_20261114T050540Z_466625.txt) · [Stage-100完整轨迹](STAGE100_RESULTS_REVIEW.md)

1,157个当帧IoU平局占63.09%，改善339次、变差338次，各约18.5%。平局只指IoU差在代码容差内，不能据此声称候选框、选择或记忆完全相同。这组结果不支持把“遇到尺寸分歧就调整”或“全部跳过调整”当作普遍可靠规则，也没有提供新的整视频AUC。

完整触发集合的微小均值仍可能掩盖少数危险状态。逐触发PPO槽位、外观最终槽位和四框明细保存在服务器，本次结果包未包含，不能仅凭均值把错误唯一归因给PPO、外观筛选或尺寸记忆。

**0307／2172：** 原PPO参考恢复为471。撤销466触发后，窗口平均IoU提高0.2828，末帧由0.4520升至0.6874，好候选帧由11/23增至19/23。两支低IoU比例均为0，说明IoU<0.2的失跟描述不足以反映IoU≥0.5的恢复质量。结果支持该状态下单次尺寸干预会影响后继；仅凭均值、末帧和好候选比例，尚不能核定参考窗口内是否连续三帧最终输出IoU≥0.5，须读取逐帧NPZ。

**0304／2172：** 锚点548，Stage-100首次观察gated好而pulse差为555。两支平均IoU、末帧、低IoU比例和好候选比例一致，末帧均为0、低IoU均9/16；启用次数由2减为1仍未修复。这表明只取消最近一次触发不足以消除这段损伤。它不能证明尺寸完全无关，也不能排除更早触发、历史尺寸或选框状态的累积影响。

**0169／2171：** 取消646触发后平均IoU提高0.0301，低IoU少1/16帧，好候选多1/16帧，末帧仍为0。改动次数由3减为2，严重失跟未被修复。该结果不足以解释完整轨迹约27点AUC损失的全部来源。

**0076／2172：** 锚点1469，同时覆盖首次观察损伤1476和原PPO参考恢复1477；26帧内两支最终输出IoU均为0，好候选帧均为0。所取消的一次干预未改变“缺少好候选”的处境；下一步应检查进入该状态以前的链条。不能直接断言目标在裁剪外，或归因于遮挡、天气等现实因素，这需要候选覆盖、响应与图像证据。

**来源获益不等于最近动作的因果贡献：** 0226／2171在321～336两支平均IoU均0.1503；0307／2171在473～488跳过后反而从0.7492升至0.7830。Stage-100中这些视频的整轨迹获益，不能简单归功于“参考恢复前最近的一次尺寸调整”。到该时刻的过去状态已经包含更早干预。

## 后续方向

最有价值的下一步是利用Stage-100／101现有缓存，向前定位0304、0169、0076进入坏状态的过程，并以0307／2172的局部改善作对照。先核定每次触发改变了哪些候选、好候选何时消失、PPO与外观最终选择何时分叉、哪些输出被接纳并进入下一次尺寸与搜索状态；再判断应修改候选保留、干预资格还是状态写入机制。

本轮已表明“只取消最近一次触发”未覆盖全部严重失败，继续仅调触发频率或冷却不足以回应这些结果。现有证据仍允许发展尺寸干预，但需要让是否干预与实际候选及后继状态证据相连。当前没有新的方法采用门槛通过，28组确认集继续封存；整视频精度和稳定性结论仍以Stage-100为准。本次只归档和复核，不修改冻结代码或启动下一编号实验。
