# Stage-120：训练支持与外观信息的提交消融

固定日期：2026-11-16（Asia/Hong_Kong）。**服务器实验已完成，回传原件已归档并复核。** 主比较EA−ER为+0.001960、区间跨零；原支持外观对原13维及打乱控制有次要正向信号，但扩展组合接管全部旧8救援点，保护失败。详见[结果复核](STAGE120_RESULTS_REVIEW.md)。以下保留固定设计与运行命令；状态 `COMPLETE_SUPPORT_APPEARANCE_COMMIT_FACTORIAL` 只表示固定计算完成，不是方法采用或能力保护通过。

Stage-119发现，旧救援缺少训练支持，普通严重错判又不全是距离异常。下一步直接检验两个可改变因素：**增加同折其他训练视频的条件后继样本，以及增加当前候选与首帧／近期预测目标的外观匹配信息。** 使用2×2主消融和两个同容量外观打乱控制，保持源组隔离。

本轮只在SGLA生成／共享评分后的q0提交机制上训练小型CPU头，复用已测一次动作后继；不训练或调用SGLA、生成器、共享评分器、PPO。不需要GPU或checkpoint，但需要原图像和冻结来源缓存。它是方法候选的开发消融，不是完整新跟踪方法的最终验证。

## 2. 两个训练支持条件

沿Stage-118的上游嵌套：每个提供者train21/held7。对待评价源组g，门控仅从该provider-held7中的其余6组拟合；g全部普通／分层／压力点、两个种子和标签均排除。

- **uniform：** 原96例=6视频×2种子×8均匀点，不新增分层点或压力点。视频→种子→例等权，精确沿用Stage-118训练支持。
- **expanded：** 同一96例，加上述6个允许训练组中所有旧压力点，包含有利／有害／平局，不按新结果筛选。其他提供者组、g全部压力点及分层独有点不进入训练。

expanded固定权重：视频等权、视频内两个有支持种子等权；某上下文若有压力点，uniform池和pressure池各占一半，各池内例等权；若无压力，该上下文uniform池占全部。报告每组实际补点数、压力权重及三类角色计数。它是**支持扩展＋固定重加权的整体处理**，不能只归因为多了几个样本；也不估计真实线上事件频率。

旧压力作为某个头的训练样本时，仅来自允许的其他6个视频；作为待评组g的压力评价时，该头完全没有使用g的任何标签。设计仍属于已消耗开发组的交叉拟合，不能因此把旧压力称新独立确认。

## 3. 24维公开外观信息

沿用原13维证据。新增24维外观证据直接从原RGB图像和冻结候选输出ROI计算，不需要网络前向，也不读取首帧之后的GT框。

参考有两种：

1. **template：** SOT允许的首帧GT初始化框。
2. **recent：** 当前帧之前30帧内，最近一个通过原冻结memory_write条件的预测框。只使用它当时的原图像和原预测框，不使用当前／未来帧作历史参考，不用GT修正；没有参考则明确标缺失。旧可信条件可能错，外观参考也可能污染。

对q0和原policy两个候选框均在同一原始RGB图像上取ROI，避免不同搜索裁剪上下文直接混比：

- 各RGB通道8-bin颜色直方图，拼接后开方归一化，点积表示颜色分布相似度。
- 可见ROI双线性采样成16×16，按固定RGB亮度系数转灰度、去均值并L2归一化，用点积表示NCC纹理相似度。

每种参考×每种描述（2×2）输出q0相似度、policy相似度、二者差、两项有效位，共20维；再加两候选可见覆盖比例、recent存在位和年龄/30，共24维。低于50%可见覆盖、空参考或平坦灰度块按各自有效位置零，不删除评价点；颜色描述仍可在灰度NCC无效时有效。

RGB/ROI计算仅用NumPy，不新增Pillow或其他依赖；图像读取仍用原checked_image校验文件SHA与尺寸。图像及参考任务先固定到manifest，公开外观缓存先保存，再训练和评价。原13维头仍为13输入，外观头为37输入。

这是轻量颜色／纹理外观线索，**不是已验证的语义身份嵌入或可靠重识别器**；相似背景、视角变化、模糊及错误历史参考可能使它失效。已有相关外观工作不否定这次后继提交条件的可检验增量，但也不能仅因加入该特征就宣布创新成立。

该表示处理同时增加外观内容、覆盖率及参考有效位／年龄；若有收益，首先归于这一整组可观测信息，不能只归因颜色或NCC。单独的外观内容贡献仍需相应后续消融，本轮不凭总收益宣称完成了该归因。

## 4. 四个主组和两个负控制

| 组 | 训练支持 | 输入 |
| --- | --- | --- |
| uniform_relative | 原uniform | 原13维 |
| uniform_appearance | 原uniform | 原13＋外观24维 |
| expanded_relative | uniform＋其他允许训练视频的pressure | 原13维 |
| expanded_appearance | 同上 | 原13＋外观24维 |
| uniform_shuffled | 原uniform | 训练时视频内打乱外观对应，评价用真实当前外观 |
| expanded_shuffled | 扩展支持 | 同上 |

uniform_relative直接复用Stage-118保存的future分数和原模型指纹，须精确保持旧预测／动作；uniform_constant复用旧future常数控制。其他五个岭头及expanded_constant新拟合。

外观打乱在**每个允许训练视频内**，联合置换完整24维向量，覆盖其种子及uniform/pressure，UID排序＋固定PCG64/SHA种子23201，一次固定不搜索。它不读取收益或待评视频。真实／打乱头使用相同训练例、权重、原始真实训练X得到的归一化和相同38个系数容量；评价均用当前真实X。报告实际特征值改变比例，重复外观可能使部分置换无变化。

它控制额外维度容量和部分视频内外观边际，但保留同视频静态信息，不是完美随机化或唯一因果证明。若真实外观优于原13维却不优于打乱控制，不能把收益直接归因于当前候选和参考的匹配关系。

所有新头回归同一真实后31帧收益差。训练内标准化、标准差<1e−6置1、clip±10、ridge1、截距不惩罚及接受阈值>1e−12固定。没有阈值／超参／checkpoint搜索，也不是PPO训练。分数不是校准后的概率。

28组每组新拟合5个岭头＋1个扩展常数，共140岭头＋28常数=168新CPU模型；另复用28旧岭头和28旧常数。新模型存为28个JSON包，原SGLA及上游模型不改。

## 5. 预定比较和保护解释

**主要比较：ordinary_uniform/all/all的expanded_appearance−expanded_relative，后31帧平均IoU差。** 它检验扩展训练支持后，外观信息是否有增量。

固定报告：

- 支持对相对特征的作用：expanded_relative−uniform_relative。
- 支持对外观头的作用：expanded_appearance−uniform_appearance。
- 原支持下外观增量：uniform_appearance−uniform_relative。
- 交互：expanded_appearance−expanded_relative−uniform_appearance＋uniform_relative。
- 两支持条件下真实外观对打乱外观的差，以及最终头对原policy、q0_all、连续性、旧myopic、扩展常数及自身同率期望。

19项策略：原policy/q0_all/连续性/旧myopic、6个头、2常数、6个头各自同率期望和两动作GT上界。每研究／视频／种子按原分析权重先算同率，再报告角色切片；不是新随机分支推理。oracle只供条件两动作上界，不可部署。

每研究按原点权重→视频内种子→视频等权。主／辅助／pressure分开，报告后继IoU、低IoU比例、保护率、实际收益、有害成本、漏益、遗憾、损失<−0.1起点数及最差收益；对照另给中位／最差／最小留一视频差、胜平负与10,000次条件bootstrap(seed23200)。多项比较未校正，重采样不重训，不当独立确认或无条件区间。

平均提高仍须检查旧救援；改善旧压力不能取代普通母体和完整轨迹。这里只有一次起点动作，随后恢复原冻结生成／评分策略，无法代表门控持续部署后的新历史。没有新完整视频AUC或采用gate，即使局部改善也仍需完整自身轨迹、稳定视频和参考恢复保护，再做封存确认。
