## 下一步建议：Stage-202 直接定位遗憾监督的匹配训练

建议停止继续挑均值窗口或校正权重，回到SGLA选层模块的学习目标。保持当前输入、6720参数残差架构、fit先验、初始化、配对抽样、优化器与256步／1024引用预算，仅对比原层间点MSE与**以真实定位遗憾定义的结构化最大间隔损失**；两组同次匹配训练。该目标是待检验的监督替代，不将标准的代价敏感损失本身宣称为新理论或已成立创新。

设六层即时IoU为y，分数为s，真值最优层`l*=argmax_l y_l`，选层定位遗憾`Δ_l=y_(l*)−y_l`。采用：

`L_regret(s,y) = max_l [s_l + Δ_l] − s_(l*)`。

对精确分数argmax选择a，有`Δ_a ≤ L_regret`；若继续保留既有1e-8的L9近最大值规则，则`Δ_a ≤ L_regret + 1e-8`。因为max项包含真实最优层，损失非负；`s=y+c`时损失为0。间隔由真实IoU差确定，不新增温度／窗口／手选margin。真值标签只在fit训练使用，held预测仍只看当前缓存特征。

这个对照检验：将训练直接约束到错误选层的定位损失，是否比平均拟合六层分数更能改善决策。它并非已经证明当前MSE是退化根因，亦不能自动解决域偏移或闭环问题。

先要求held对匹配MSE／固定先验和自身无对应期望的增量、源组和双seed一致性，再决定是否进入完整轨迹验证；同时报告实际Transformer块数／选择分布，不能只用即时IoU声称动态深度已成功。固定L7仍不得直接采用（194完整轨迹曾受损），确认集不打开。
