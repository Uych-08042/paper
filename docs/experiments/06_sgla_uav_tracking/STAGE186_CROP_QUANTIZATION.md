# Stage-186 搜索裁剪取整与移动方向对照

Stage-185 的 0091 在保持 67 像素裁剪边长时，左上角的微小整数变化改变了 L9 的 Hann 选峰。Stage-186 检验预测图的变化是否依赖实际取整窗口变化，并比较观测方向与同像素幅度反方向的后效。

## 对照构造

复用 Stage-185 的 19 个变化点和 8 个稳定窗口。在每个写回点的第一后续帧固定模板、L9 和基准写回框宽高。以只改映射分支为当前裁剪，使用只换中心分支的原始浮点位移定义对照。

| 处理 | 裁剪构造 |
| --- | --- |
| 当前 | 保持基准中心 |
| 同一取整窗口 | 沿观测方向移到窗口首次取整变化之前，采用基准与边界之间的中点。若观测位移本来就在同一窗口，保留实际位移 |
| 仅水平／仅垂直 | 各自保留观测位移的一个分量 |
| 实际方向 | 执行 Stage-185 的中心位移 |
| 等幅反向中心 | 在浮点坐标中反转中心位移 |
| 等幅反向像素 | 反转取整矩形的实际二维位移，保证整数位移幅度相同 |

另保留原生当前裁剪分支以评价稳定性和事件伤害。0348 第 361 帧保留 Stage-185 的只换宽高分支作为尺寸对照，单列观察。

## 读出和续跑

- 报告实际取整裁剪、中心到目标的距离、目标覆盖、Hann 选峰、三张预测图的最大差异、常规输出与全网格最佳 IoU。同一取整窗口的预测图须复现。同尺寸组再统一回映到基准父框中心，测新裁剪对网络预测的作用，并报告水平与垂直位移的当帧交互。
- 写回各组实际输出并恢复原生路由，后效包括第一个后续帧，最多 128 帧。同环境复核 Stage-185 已观测的 L9 分支，并复用在相同帧得到完全相同写回框的续跑。其他支持的运行环境在同卡重做。结果分报实际跨边界、完整 128 帧和稳定样本，同时列出观测方向和等幅反向像素的逐源差值。全部基于已有开发事件。

## 结果

同 L20 完成 27 个起点和 217 次探针，新增 16,350 次后继调用。六张回传表及决策的哈希通过校验，Stage-185 共享分支的格点、当帧 IoU 与后效一致。已复算对照差值和源组汇总。决策指纹 `318e1a59f5322d3458f59c5b3fca8bb1240d7d648db7301e8ebbdedda0cb5741`。

- 27 个取整窗口内移动的响应、宽高和偏移图最大差异均为零，Hann 格点全部相同。15 个完整变化窗内，实际方向有 7 个改选格点，等幅反向像素有 11 个。实际方向与反向用同一基准坐标解码时，后续第一帧 IoU 按 14 个源组等权相差 +0.0972。恢复各自坐标映射后相差 −0.0048。
- 实际方向相对等幅反向像素的 128 帧后效平均差为 +0.0427，中位数 +0.0008。剔除贡献最大源组后约 −0.0002。8 个稳定窗口均未出现预设事件伤害。
- **0091** 的原裁剪下一帧 IoU 为 0.0303。等尺寸下，水平和垂直单轴对照均为约 0.674，实际方向为 0.615，等幅反向像素为 0.643，四组均出现长窗挽救。反向像素裁剪中心比原裁剪离目标更远，仍能改变选峰并恢复。
- **0176** 的窗口内移动保持预测图、选峰和 710 像素裁剪不变，但因浮点回映改变，后续平均 IoU 较当前裁剪提高约 0.571。**0089** 的窗口内对照也保持预测图不变，后续较当前裁剪下降约 0.575，并造成恢复损失。**0348** 的尺寸对照保住了稳定性，多数同尺寸中心对照延续了原恢复损失。

结果支持两条不同的反馈途径。跨取整边界会改变预测图和读出，取整不变的浮点映射也可能改变后续轨迹。已有样本尚未建立普遍有效的中心移动方向。

## 下一步

先用缓存验证相邻裁剪是否提供可重复的目标匹配证据。把各裁剪的预测框统一放回图像坐标，合并相同取整窗口，测同一图像目标位置是否反复得到支持。用相同候选和搜索预算比较邻域一致性、当前单裁剪输出与最高响应的选择，利用已观测续跑检查挽救覆盖和稳定性。若匹配证据集中于少数事件，先补独立失跟和稳定对照，再做在线门控。
