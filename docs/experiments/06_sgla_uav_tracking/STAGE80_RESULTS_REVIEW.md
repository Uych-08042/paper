# Stage-80 完整轨迹尺度保护结果

同一 L20 完成 12 个开发视频、84 条完整轨迹、338,125 次搜索。原生与原尺度 PPO 的公开框相对 Stage-76 最大误差为 0，原尺度 PPO 动作差异为 0。已核对报告指纹、五张表的 SHA-256、预算及逐种子到逐视频的汇总。原始服务器推理缓存未在本机复查。确认集推理为零。 [固定协议](STAGE80_FULL_SCALE_CONSENSUS.md) · [回传原件](results/stage80_results_20261108T104119Z_342748.txt)

**开发门槛未通过。** 加保护相对原尺度 PPO 低 0.9463 AUC 点，视频配对 95% 区间 [−2.9652, +0.4302]，6 胜、3 平、3 负。低 IoU 增加 1.50 个百分点，最长失跟比例增加 1.70 个百分点。相对仅限幅提高 0.8829 AUC 点，区间 [−0.0372, +2.6662]。相对原生的均值差为 +2.8381 AUC 点，区间 [−5.1164, +12.9158]，可靠帧 AUC 低 2.9581 点。两种子相对原尺度 PPO 的均值差为 +0.1879 和 −2.0806。保留确认集，当前配方不进入确认评估。

## 逐视频变化

- **0204 的保护作用延续到完整轨迹。** 种子 2172 的限幅组在第 664 帧失跟，AUC 51.4606；加保护后没有失跟事件，AUC 72.6436，接近原尺度 PPO 的 72.6333。该轨迹记录一次换框。去掉 0204 后，加保护相对限幅的平均 AUC 增益只剩约 +0.00026 点。
- **0304 的短窗收益未转化为整段收益。** 种子 2172 从首帧启用限幅后，首次持续失跟由原尺度 PPO 的 1090 帧提前至 556 帧，AUC 从 43.8068 降至 22.2526（加保护）。整段内保护换框六次，首次失跟与仅限幅相同。Stage-79 从原历史第 1075 帧出发，Stage-80 的限幅组从首帧生成自身轨迹，两者起点不同。
- **稳定保护仍有缺口。** 0003 在三个 PPO 臂的两种子均复现原来的短失跟，0304 的种子 2172 也仍使该视频计为新增失跟。0176 的种子 2171 在两限幅臂丢失末段恢复，AUC 从 66.7158 降至 60.3748。

加保护组的 27,050 个评价帧中，840 帧的取整裁剪因限幅实际改变，543 帧进入一致性检查，15 帧换框。少量动作变更可以显著改变个别长轨迹，当前收益集中在 0204。

## 接续

保存此负结果并停止迭代当前统一限幅加近分保护。若继续研究尺度机制，优先检验固定四搜索预算内同时保留原始尺度与限幅尺度的候选，按开发视频完整轨迹衡量早期错选、后续候选供给和恢复。使用原尺度 PPO 和当前两限幅臂作消融参照。任何新配方都先在开发视频检验，确认集继续封存。
