# Stage-160 保留原生层的六选一

Stage-159 的后续监督选择器在 328 个留出起点共换层 247 次。后续 32 帧平均 IoU 相对原生 +0.192 点，新增连续恢复 2 次，新增连续低 IoU 2 次。本轮固定该选择器，只校准相对原生的预测收益门槛。

## 校准及评估

每个外层拟合折内部，逐一留出一个视频源组，用其余源组复现 Stage-159 的后续收益岭回归。在内部留出的起点预测六层得分。候选层沿用 Stage-159 的最高分选择，门槛以候选相对原生层的预测收益表示。

在内层预测上枚举非负门槛。从没有新增连续低 IoU 或丢失已有连续恢复的门槛中，选后续 32 帧视频平均 IoU 收益最大的。并列时保留较高门槛。然后用完整外层拟合折的原 Stage-159 权重预测外层留出组，核对门槛应用前的逐起点选择与归档一致。候选的预测收益严格超过门槛时才换层。对照原生、Stage-159 直接选层和零收益门槛。整个实验使用 Stage-159 阶段已有的六路短程轨迹和特征，零 GPU 推理，不读取图像。

结果按视频平均，包含全样本、均匀起点、历史低响应和原生全程稳定窗口。比较相对原生与 Stage-159 的 IoU、留一视频、换层次数、连续恢复新增／丢失和新增连续低 IoU。重点核对 0176／163 与 0226／174。真实门槛的结果仍需服务器缓存。

## 已完成的缓存上界

用 Stage-159 回传逐起点重算。只在原生层和 Stage-159 已选中的层之间用未来真值做事后选择，保留有正收益且不引入上述两类损伤的换层。328 个起点中保留 110 次换层，32 帧平均 IoU **0.60942**，相对原生 **+0.549 个 IoU 点**，相对 Stage-159 **+0.357 点**。两次新增恢复均保留，两个新增低 IoU 窗口均避开。该结果依赖未来真值，量化了这一批固定候选的保护空间。

## 运行

同步代码后在服务器仓库根目录运行。使用 `STAGE159_ROOT` 指向此前服务端完整结果目录，含逐起点 NPZ 特征及 `stage159_models.json`。共享的总体进度条默认每 15 秒刷新，结果包位于 `output/stage160/calibrated_layer_veto_v1/stage160_results_*.txt`。

```bash
mkdir -p output/stage160
nohup bash tools/run_stage160_layer_veto.sh >> output/stage160/run_stage160.log 2>&1 < /dev/null &
tail -f output/stage160/run_stage160.log
```
