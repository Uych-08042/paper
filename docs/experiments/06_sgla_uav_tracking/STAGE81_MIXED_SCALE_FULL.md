# Stage-81 同预算混合尺度完整轨迹消融

Stage-80 从首帧启用统一限幅后，0304 的首次持续失跟提前。Stage-81 只修改候选裁剪的构成，在四个搜索位中同时保留原始尺度与限幅尺度。 [Stage-80 结果](STAGE80_RESULTS_REVIEW.md)

## 固定设计

在同一个预测历史上，q0 和 q2 始终保留原规则的最新预测尺寸，中心分别是当前历史的最新中心与滞后一帧的中心。q1 和 q3 默认仍用原规则的历史中位尺寸。若最新预测尺寸经过 Stage-78 限幅，则在两个对应中心分别构造限幅尺寸候选。只有该取整裁剪同时区别于对应的原始最新尺寸裁剪和历史中位尺寸裁剪时，才替换 q1 或 q3。判断只计算裁剪坐标。

限幅沿用最近最多五个限幅状态宽高的逐轴对数中位数和 1.25 倍上限。所有搜索沿用原生 SGLA 模板、权重和解码。各臂自己发布原始候选框并推进历史。PPO 权重和原始历史特征接口固定。混合布局会改变 q1、q3 原有的候选含义，PPO 的适用性也在本轮闭环中接受检验。

| 实验臂 | 每帧搜索 | 候选构成与选择 |
|---|---:|---|
| `native_sgla` | 1 | 原生 SGLA |
| `original_ppo` | 4 | 原尺度候选＋冻结 PPO |
| `mixed_ppo` | 4 | 混合尺度候选＋冻结 PPO |
| `mixed_guard` | 4 | 混合尺度候选＋冻结 PPO，仅在实际替换裁剪时启用 Stage-80 一致性保护 |

原尺度 PPO 和原生基线在同一物理 GPU 重新运行，另记录与 Stage-76 缓存的差异。Stage-80 两个统一限幅臂作为历史结果引用。12 个开发视频、两个冻结 PPO 种子，共 84 条完整轨迹、338,125 次搜索、2,366,875 次 block 调用，零训练。28 组确认集仅绑定指纹，本轮零推理。

主比较固定为混合 PPO 相对原尺度 PPO；混合加保护单列。按视频报告 AUC、低 IoU、最长失跟、新增失跟，以及裁剪替换、选中限幅候选、好候选供给与漏选。种子先在视频内平均，再等权汇总。开发门槛沿用至少 +0.5 AUC 点、视频配对区间下界大于零、低 IoU 和最长失跟不劣于原尺度 PPO、原生稳定视频零新增失跟。次比较单独报告，主比较结果不随次比较结果改变。

## 运行

```bash
cd ~/workspace/paper
mkdir -p output/stage81
nohup bash tools/run_stage81_mixed.sh > output/stage81/run_stage81.log 2>&1 < /dev/null &
```

使用已分配 L20 或 L40。依赖 Stage-76、77、80 的原始运行目录和原生 SGLA 检查点。可用 `STAGE76_ROOT`、`STAGE77_ROOT`、`STAGE80_ROOT`、`STAGE81_ROOT`、`STAGE81_GPU` 和 `CHECKPOINT` 覆盖。续跑绑定同一运行指纹与物理 GPU，并复用已提交的整视频缓存。换卡使用新的 Stage-81 输出目录。

完成后用 `cat output/stage81/run_stage81.log` 查看结果包路径，回传 `stage81_results_*.txt`。已完成的目录可用 `--pack-only` 校验导出。
