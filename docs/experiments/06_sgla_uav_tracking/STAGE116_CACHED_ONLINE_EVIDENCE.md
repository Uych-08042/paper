# Stage-116：在线证据与匹配后继收益审计

固定日期：2026-11-16（Asia/Hong_Kong）。状态：实现及本机验证完成，正式服务器缓存审计待运行。

Stage-115表明，一次q0动作可以改善后继，也会阻断成功救援，甚至出现当帧修正、未来变差。因此本轮检验：**当前响应与历史几何提供的公开证据，能否区分哪些起点值得保留q0，并在匹配后继中超过相同保护率的无选择对照？**

本轮是开发证据审计，复用现有缓存，不训练门控、生成器、评分器或PPO，不调用图像解码或SGLA GPU推理。来源生成器/评分器的数值重放仍是CPU计算。本轮不产生完整轨迹或新AUC，不设置方法采用门槛。

## 2. 明确的在线输入白名单

`online_evidence(observation, history, scorer)`只读取当前四个候选框、4×24响应/几何特征、冻结共享分数和所选序号、预测均值/条件半径/激活位、此前最多五个预测框，以及冻结评分器的标准化参数。没有当前/未来GT、角色、视频ID、未来分支结果或来源未来帧。

已存缓存没有新的外观描述子，本轮不补算外观相似度。原始响应强度、Hann峰和预测范围均不是已校准的正确概率。

九项方向固定的证据，正值按定义表示较支持q0，不因观察标签而翻转方向：

| 证据 | 定义 |
|---|---|
| hann_advantage | q0 Hann峰−原选择Hann峰 |
| raw_advantage | q0原始峰−原选择原始峰 |
| psr_advantage | q0 PSR−原选择PSR |
| entropy_advantage | 原选择熵−q0熵 |
| continuity_advantage | 原选择中心至历史速度外推中心的距离−q0对应距离，除以前框面积平方根 |
| size_stability_advantage | 原选择相对历史中位log宽高的平均绝对偏离−q0对应偏离 |
| forecast_advantage | 原选择相对预测均值的最大半径归一化偏差−q0对应偏差 |
| agreement_advantage | q0与其他不同框的平均连续IoU−原选择对应支持；精确重复框不重复投票 |
| score_advantage | q0冻结共享分数−原选择分数，越接近0表示原替换的评分优势越小 |

另记录4个上下文量：两框中心冲突、log宽高冲突、最大条件半径、评分标准化特征超过原裁剪界的比例。它们只作分组描述，不假定越大就该保q0。中心外推为最后中心加最近一次中心增量，不做新运动模型拟合；预测未激活时兼容性和半径描述记0。

这些证据并非互相独立。预测范围以当前自身历史为参照，坏历史下“符合预测”仍可能错误；多框一致也可能是相关的错误输出。

## 3. 固定比较规则

所有规则只在原实际输出与q0框不同时可能干预，序号不同但框完全相同不计物理替换。比较使用固定epsilon=1e−12，平局沿用原选择，不搜索阈值：

| 规则 | 当前帧保护q0的条件 |
|---|---|
| policy | 不保护，原冻结共享选择 |
| q0_all | 所有物理替换均回到q0，作为统一回退控制 |
| hann_pair | hann_advantage>epsilon |
| continuity_pair | continuity_advantage>epsilon |
| corroborated | Hann、原始峰和中心连续性三项优势均>epsilon |

这三项候选规则代表响应、运动连续性及联合佐证的固定假设，**不预称为最终方法**。它们只在q0与原选择之间判断，不重新在四候选中找最高Hann框，不改变候选生成。

匹配后继另外提供三项`__rate_expected`控制和`future_oracle`上界，共九种策略。每个同视频/评分种子上下文，先在其全部34起点中的可用子集计算相应规则的保护比例，再用该比例计算均匀随机挑选同样数量起点时的期望效用。该概率在按角色汇总前固定，不用分角色标签重新匹配保护率，不引入随机重训。

34起点只分布于28条种子轨迹，同率控制支持稀疏：只有一个起点的上下文，或规则全保护/全不保护的上下文，期望控制必然等于原规则。配对表明确给`rate_informative_contexts/anchors`，只数保护概率介于0和1的上下文/起点；不把大量平局解释成已经证伪或确认选择能力。

`future_oracle`仅在已测两条后继中逐起点选择均值较高的一条，是GT后继上界，不是在线规则；两动作均差时，上界也可能很低。

## 4. 后继标签和评价

每起点重读原公共点和两分支，按Stage-115原实现审计历史、解码、动作和来源桥接，重算后31帧平均IoU。起点当帧不混进后继指标。

四类标签由已测后继定义，独立于原GT选点角色：

1. `both_low`：两条后继平均IoU均<0.2，优先记此类；并非每帧都低。
2. `q0_better`：至少一条均值≥0.2且q0_once−policy>epsilon。
3. `policy_better`：至少一条均值≥0.2且policy−q0_once>epsilon。
4. `tie`：其余平局。

同时保留连续后继差。九个方向固定证据的加权AUROC预测“q0_once后继差>0”，仅排除差值平局；both_low中有非零差的点仍纳入，避免藏掉困难点。先视频等权，再视频内有支持种子等权，再种子内起点等权。无正类或无负类时AUROC为空，不填0或翻转成较高AUC，也不根据这34点挑最佳特征/阈值。

每规则报告后继平均IoU、低IoU比例、保护概率、对policy的实际收益，以及两动作上界的遗憾。主要对比预先全部列出：三项候选规则分别减policy、q0_all和各自同率期望控制。按all/historical/expanded、全部起点/三个原选点角色分列；先种子内起点、再视频内种子、最后视频等权，视频层10,000次条件bootstrap，seed23160。表中区间未经多重比较校正，只作条件诊断，不据单项正区间宣布PASS。

34个起点是已消耗、按GT角色选出的开发材料，没有新外部验证含义。全量58,094状态避免只报几例当前收益，但尚没有这些状态的任意替代未来；不能把有害替换拦截率写成实际失跟预防率。
