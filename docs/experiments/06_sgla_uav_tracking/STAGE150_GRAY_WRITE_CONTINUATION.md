# Stage-150 校准灰度改选的同起点续跑

Stage-149 的首帧灰度单项评分在 0.025 门槛下改选了 14 个原生状态。0089／1159 当帧 IoU 从 0.4698 升到 0.5108，0169／881 从 0.2893 降到 0.0696。本轮测量这类差异写回后如何影响后继搜索和选框。 [Stage-149 结果](STAGE149_RESULTS_REVIEW.md)

## 对照

- 使用 Stage-149 留出校准后实际改选的全部 14 个原生状态。每个状态单独回放，同一视频上的相邻起点各自从原始缓存开始。
- 起始帧两路共用 Stage-121 冻结的父框、搜索裁剪和响应图。回归组写入原逐框回归输出，灰度组写入 Stage-149 已接受的备选框。以保存的候选格点和 IoU 核对两次写入。
- 从下一帧开始，每路按自己的上一帧输出裁剪一次，共用首帧模板、原始 SGLA 和 Stage-143 对该视频源组留出的冻结回归评分器。后继帧两路都用回归选框。标注仅用于初始化和离线核对。
- 最多续跑到起点后第 32 帧。完整 8 帧和 32 帧分别汇总均值、逐起点胜负和连续 3 帧好框（IoU ≥ 0.50）或严重低 IoU（IoU < 0.20）的变化。视频结尾不足窗口的起点保留在逐窗表中，完整窗口均值使用有完整有效标注的起点。同一源组先取均值，再跨组等权汇总。无效标注打断连续事件。

本轮估计一次改选在已观察开发状态中的后效。起点由 Stage-149 实际触发确定。整段 AUC、稳定视频误触发率和独立确认集表现需要另行验证。

## 运行

同步代码后，从服务器仓库根目录在 `sglatrack-test` 环境运行。需要原 SGLA 权重、VisDrone-SOT 帧和 Stage-76、89、93、121、133、143、149 的完整产物。首轮可用 L20 或 L40，两个分支在同一卡上推理。若换卡后需继续尚未完成的运行，请用 `STAGE150_ROOT` 指定新目录。

```bash
mkdir -p output/stage150
nohup bash tools/run_stage150_gray_write.sh > output/stage150/run_stage150.log 2>&1 < /dev/null &
```

默认目录为 `output/stage150/gray_write_continuation_v1`。脚本核验产物后生成 `stage150_results_*.txt`，包含决策、汇总、逐起点窗口和逐帧表。日志可用 `tail -f output/stage150/run_stage150.log` 查看。
