## 分解如何读

S为普通短分支头，P为末帧保持头；hS／hP为两种来源历史的预测父框。表中第一条路径固定为：

```text
自身差 D = value(P,hP) - value(S,hS)
        = [value(P,hS) - value(S,hS)] + [value(P,hP) - value(P,hS)]
        = 共同S起点的换头差 M + 固定P头的起点差 H
```

当帧M是在相同特征上更换头的条件差；32帧M还包含这个头导致的后继状态变化。D=M+H是精确记账，并不是唯一的全轨迹因果百分比分摊。不同起点的中心、宽高及实际裁剪都会变化，不能把H只理解为中心偏移。

## 零差、分岔时间与解释边界

50条共同起点对比都在锚点当帧出现浮点框差，下一帧出现取整裁剪及响应图差。响应分支参数保持冻结；后继响应变化可以由输入变化产生，不能据此认定响应权重被修改。这个分岔顺序既出现在获益分支，也出现在受损或IoU差为0的分支，顺序本身不能证明效果方向。

C01、C02、C03的2133自身IoU差及若干共同起点分支差均为0，但其框、裁剪和响应仍有变化。IoU差为0不是两个actor完全相同；尤其当帧五头IoU都为0时有明显的指标地板效应。相同均值差也不等于每一帧的IoU相同，不从差值表推断未提供的绝对分支均值或恢复时刻。

每个案例都来自已消费结果。125条重叠分支、两个种子及50条比较不是新的独立视频样本；本轮不做方法PASS、泛化或部署收益声明。32帧的均值和末帧读数分别判断，局部窗口未恢复不等于原视频末尾未恢复。
