# Stage-140 搜索父框中心与尺寸的同帧交叉

Stage-139 中，0237 第 243 帧的原生和跨块分支都完整覆盖目标，且标准输出 IoU 均为 0。原生裁剪的全网格最佳为 0.5087，跨块裁剪为 0.3205。本轮分别交换父框中心和尺寸，检查哪一项变化影响候选供给。 [Stage-139 结果](STAGE139_RESULTS_REVIEW.md)

## 固定比较

| 组别 | 父框中心 | 父框宽高 |
| --- | --- | --- |
| `native_center_native_size` | 原生历史 | 原生历史 |
| `cross_center_native_size` | 跨块写回历史 | 原生历史 |
| `native_center_cross_size` | 原生历史 | 跨块写回历史 |
| `cross_center_cross_size` | 跨块写回历史 | 跨块写回历史 |

0237 第 243 帧为主比较，第 244–250 帧检查两条历史上的差异是否重复。0089 第 1165–1166 帧保留为响应排序对照。0349 第 409 帧使用原生和跨块最高 Hann 峰历史作稳定对照。共 11 个预定帧，最多 44 次搜索。只合并同一帧完全相同的浮点父框，另计相同像素裁剪。模型、初始模板、搜索倍数及输出尺寸均固定。每组从缓存父框独立推理并度量，不继续写回。

## 结果判读

观察全网格最佳 IoU、有限峰池最佳 IoU 和标准输出 IoU。分别比较在固定尺寸下改变中心、在固定中心下改变尺寸，以及两项的交互。已知跨块父框的两个分量中，哪一项恢复原生值能重新得到好框，会在 `stage140_effects.csv` 直接给出。`stage140_frames.csv` 记录实际裁剪位置、边长、覆盖比例和输入真值框短边，用于确认预期的裁剪变化确实发生。

SGLA 用父框中心和由宽高几何平均确定的方形裁剪边长。尺寸交换会同时改变可见上下文和输入目标尺度，结果适用于这次联合变化。宽和高各自的作用以及更长轨迹的收益仍需后续对照。

## 运行

```bash
bash tools/run_stage140_crop_center_size_cross.sh
```

默认输出 `output/stage140/crop_center_size_cross_v1`。可用 `STAGE140_GPU` 指定逻辑 GPU。同 Stage-139 运行环境时校验两个原始组的响应图、层选择与输出框，换卡时仍校验裁剪像素和记录框偏差。脚本生成 `stage140_results_*.txt`。
