# Stage-124 候选独立评分对照

状态：**已实现并通过本机合成测试，正式训练和评价待服务器缓存。** 这是同一状态、同一候选四框的离线对照。目标是检验删除同帧候选间关系后，评分能否提高好框采用率并保护已有的正确选框。

## 两组评分器

| 组别 | 输入 |
|---|---|
| 关系评分 | 原 32 个基础和关系量及其平方，64 维。 |
| 独立评分 | 保留 24 个候选自身观测和 2 个历史参照特征及其平方。屏蔽平均／最大候选重叠、与当前 q0 的重叠、平均候选中心距离、平均尺度差和 Hann 相对排名及其平方。52 个有效输入补零到 64 维。 |

两组均用现有共享 MLP 64→32→1、相同训练行和视频来源权重、相同当前 IoU 监督、相同初始化种子、学习率、迭代数、批次顺序和决胜规则。每个头名义参数量 2,113。独立组的屏蔽列始终为零，实际参与输入更少。给定同一候选的观测和同一过去历史，替换别的当前帧候选不会改变独立组对该候选的分数。评分器仍可在四框中比较得分并选出一个。此轮固定 SGLA、候选生成器和所有当前候选，未引入新的外观分支。

## 缓存与留出方式

使用 Stage-121 L40 的生成共享和备用共享各 56 条轨迹。每条轨迹均匀取 64 帧，合计 7,168 个普通状态，按帧号取样。各实际启用备用裁剪的 358 帧保留，和普通帧去重后有 7,513 个可用于训练或留出评价的状态。另保留原生恢复时刻在对应两组缓存上的 52 次观察，用于压力评价；与已有帧去重后，共 7,561 个评价状态。压力组与普通组可重叠，分别统计。

每个待评来源只使用同一个 Stage-112 上游提供者折里其余 6 个来源拟合。该提供者的原生成器和原共享评分器训练均在这一折的 7 个来源之外。本轮不把其他上游折的轨迹拿来拟合当前待评来源，待评来源在本轮拟合中整体排除。按归档核对，每个头有 1,544～1,693 个训练状态；28 个待评来源 × 2 种输入 × 2 个种子，合计 112 个 CPU 小模型。初始训练样本仅用均匀帧与实际备用触发帧，尚未被这两种采样纳入的恢复帧专用于评价。这些仍是既有开发视频上的留出诊断。

主比较为 7,168 个普通状态的配对当帧 IoU，视频来源等权，另报两个模型种子的效果。报告好框选中率、低 IoU 比例、相对关系评分和原记录动作的好框增选及丢失。单列原 q0 是好框的普通帧、原记录动作在 q0 失败时选到好框的普通帧、358 个备用触发、其中 80 个匹配触发、9 个新增好框，以及原生恢复时刻。沿用 IoU ≥ 0.5 定义好框，IoU < 0.2 定义低 IoU。

本轮输出每个模型种子在保存状态上的选框。正式结果没有新视频轨迹、AUC、GPU 搜索、图像读取或确认集推理。固定候选上选框改善仍需完整轨迹检验稳定性和恢复。 [Stage-123 结果](STAGE123_RESULTS_REVIEW.md)

## 服务器入口

在保留 Stage-76／89／93／112／121／122 产物的服务器仓库根目录运行：

```bash
bash tools/run_stage124_candidate_independence.sh
```

脚本使用 CPU，完成后会打印 `output/stage124/candidate_independence_v1/stage124_results_*.txt`。回传包包含决策、模型训练范围、策略与配对统计、逐视频和逐点输出。可用 `--pack-only` 重新核对及打包。
