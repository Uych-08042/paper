# Stage-141 固定裁剪尺寸的外圈背景干预

Stage-140 中，0237 第 243 帧的大裁剪同时引入了额外背景和较小的输入目标。本轮在保持大裁剪几何和输入尺度的条件下，只替换小裁剪以外的图像像素，检查外圈内容会否影响候选。 [Stage-140 结果](STAGE140_RESULTS_REVIEW.md)

## 固定比较

沿用 Stage-140 的 11 帧。分别在原生中心和跨块中心上比较四组，共 22 对中心、88 次搜索。已核对 22 对裁剪在像素坐标上严格包含。所有组使用同一原始模型、首帧模板和标准 Hann 解码。

| 组别 | 实际输入 |
| --- | --- |
| `small_full` | 原小裁剪 |
| `large_full` | 原大裁剪 |
| `large_mean_fill` | 保留小裁剪范围的原始像素，小裁剪以外使用固定 RGB 均值填充，沿用大裁剪 |
| `large_edge_fill` | 保留小裁剪范围的原始像素，小裁剪以外用边缘复制填充，沿用大裁剪 |

小裁剪有效区域由缓存预测父框和原采样规则确定。真值用于推理后的覆盖和候选评价。填充在原图坐标完成，保留区域的原始像素不变，三组大裁剪的框映射和输入目标尺度相同。报告小裁剪未完全保留真值框的配对并单列完全保留子集。两种填充对照用于判断结果对替换方式的敏感性，填充自身仍会改变背景边界。

## 判读

- 大裁剪内，分别比较两种填充和原大裁剪的标准输出、有限峰池和全网格最佳 IoU。若两种填充在目标像素完整保留时都恢复了候选，支持外圈内容参与了供给变化。
- 小裁剪与填充大裁剪保留同一真实图像区域。两者的对照同时涉及重采样、目标相对网格位置和填充，适合检验原尺寸效应的剩余部分。
- 主比较为 0237 第 243 帧，后七帧看方向是否重复。0089 和 0349 分别保留为排序和稳定对照。所有结论基于已选开发帧。本轮无写回、训练和新视频轨迹。

## 运行

```bash
bash tools/run_stage141_crop_context_probe.sh
```

默认输出 `output/stage141/crop_context_probe_v1` 并生成 `stage141_results_*.txt`。可用 `STAGE141_GPU` 指定逻辑设备。同 Stage-140 运行环境时核对原小裁剪、原大裁剪的响应图和输出框；换卡时仍核对像素哈希和框差。各填充组核对与原大裁剪的父框和缩放一致。
