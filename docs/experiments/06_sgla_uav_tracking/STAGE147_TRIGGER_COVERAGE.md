# Stage-147 候选改选的触发条件覆盖审计

Stage-146 中，原生严重低 IoU 状态有 172 个池内好框被默认回归漏选，全部未进入外观比较。Stage-147 检查回归分差、框间重叠和外观可用性各自排除了多少机会。 [Stage-146 结果](STAGE146_RESULTS_REVIEW.md)

## 固定输入

- 复用 Stage-146 的 4,754 个冻结状态、Stage-143 的默认框和全网格池。逐帧核对 Stage-146 的原始候选筛选结果，包括放行候选数、格点顺序和可选好框的 IoU 上限。
- 对池内每个备选记录其相对默认框的回归分差、两框的连续坐标 IoU，以及双方是否都能计算近期颜色、首帧灰度相似度。原阈值为分差 ≤0.15、框间 IoU ≤0.25。
- 逐候选汇总四种情况。只被分差排除、只被重叠排除、被两者排除、两者均通过。同一帧可能有不同候选落入不同情况，备选计数可以直接相加，按帧计数可能重叠。

## 同样本覆盖对照

离线评估预设网格，共 96 种组合。分差上限取 0.05、0.15、0.25、0.40、0.60 或不限。框间 IoU 上限取 0.10、0.25、0.40 或不限。外观条件为不限、近期颜色可用、首帧灰度可用或两种均可用。单独放宽一项时保留另一项及外观要求的对照。

分别统计放行的备选数、涉及帧和视频源组。默认框 IoU <0.50 而备选 IoU ≥0.50 时为新增好框机会。以 281 个原生严重低 IoU 且响应网格存在好框的状态为主，另看 19 个失跟起点、18 个全网格独有好框机会、分支回放和 0089 的重点帧。在抽样的 110 个稳定窗口内，统计默认框达到 IoU 0.50 时，放行的备选中有多少低于 0.50 及多少低于 0.20。放行坏框表示误改选机会，最终选择结果仍需另测。

本阶段核对原像素并重算外观可用性。仅 CPU，无新增搜索、模型拟合或选择策略验证。保留完整状态和候选明细用于复核。
