# Stage-152 只换搜索中心的整段闭环结果

**Stage-151 的短程平均收益没有延续到整段运行。** 只换中心的 AUC 为 55.4456，相对完整灰度、回归和原生 SGLA 分别差 −1.2245、−5.1994 和 −8.5149 点。对完整灰度的配对区间跨零，同时低 IoU 比例和最长失跟占比的均值更高。 [实验协议](STAGE152_CENTER_CLOSED_LOOP.md) · [服务器原始回传](results/stage152_results_20261120T064318Z_611857.txt)

## 短程结果在整段轨迹中的表现

- **0089。** 两组均在 1159 帧首次改选，当帧报告 IoU 同为 0.5108。只换中心的整段 AUC 为 63.8371，完整灰度为 53.4921，回归为 63.8095。该视频相对完整灰度的优势在整段仍可见。
- **0085。** 两组都在 216 帧首次改选，运行至 690 帧均未触发该次改选。只换中心／完整灰度／回归的 AUC 为 10.9286／43.2742／36.4674。Stage-151 的恢复来自冻结起点；Stage-152 累积的搜索历史和触发状态已经改变。
- **触发范围。** 两种灰度方案各有 18 个视频至少触发一次，完整框与只换中心分别触发 156、142 帧。相对各自裁剪下的同帧回归框，报告框 IoU 分别有 43、31 帧改善，45、44 帧下降，其余持平。该比较以触发帧自身裁剪为条件，表中的 AUC 对照则使用各组完整轨迹。

回归基线自身相对原生 SGLA 已下降 3.3155 AUC 点，配对区间为 [−11.1983, +4.4684]。在同一回归基线上加入只换中心，AUC 又下降 5.1994 点。整段证据未支持这条规则作为主方法。研究范围仍为已消费的开发视频。
