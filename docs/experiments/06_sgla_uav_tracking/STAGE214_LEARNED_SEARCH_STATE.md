# Stage-214：下一帧搜索状态学习的匹配监督对照

本阶段仅实现先导验证，不预设有效。依据Stage-213：固定原生状态下，两路输出的GT上界仍不能保住12次mm匹配恢复；单纯输出二选一不足以保护既有能力。检验下一帧父框是否应当独立于当前输出学习，同时检验额外覆盖约束是否有增量。确认集继续封存，旧代码和权重不改。

所有双路臂沿用212的一裁剪/共享L1–L6/原始MLP一次/同一原生所选候选块两读出/CENTER两次。对外输出总取适配框。冻结SGLA、选择器、CENTER、空间适配器及缓冲；只训练下一帧父框更新器。不能将本阶段称为已实现动态选层、串行增加Transformer层或新候选选择器。

## 搜索状态的参数化

原裁剪为正方形，边长为 $L=f\sqrt{wh}$，固定配置 $f=4$（程序从实际tracker参数读取）。父框中心与面积的平方根决定裁剪；长宽比在此公式下没有独立作用。因此只学习中心平移2维和对数尺度变化1维，不随意增加两个宽高自由度。

更新器输入为未适配F6的模板token均值、搜索token均值，加raw与adapted两框各自相对当前父框的归一化中心差/对数宽高比，共 $2C+8$ 维，真实骨干 $C=192$ 时为392维。没有真值、未来帧、候选层遍历或事后事件标签。仅fit数据估计每维均值/标准差，std下限1e−6只为数值稳定。

MLP为 `(2C+8)→32→3`，Tanh隐藏层，无dropout；末层零初始化，原生raw框作为残差基点。输出 $d=(d_x,d_y,d_s)$：以raw面积平方根归一化中心平移，对数尺度修正；保持raw长宽比，生成下一帧父框。中心限制在当前图像边界，面积平方根限制在1像素至图像最长边，属于物理数值界限，不是按失跟分数调参。零残差在合法raw边界内精确保留raw父框。父框允许延伸到图像外，沿用原采样padding。

## 两个同预算目标

`forecast`：用fit视频下一帧GT中心和几何平均尺度作为目标，归一化中心差与对数尺度用三维平均SmoothL1回归。该尺度目标维持原裁剪配置的目标分辨率，防止只扩大区域；它不是已证明的最优上下文。

`coverage`：同一模型、初始化、fit状态、归一化、抽样和优化器，在上述回归上加下一帧GT超出预测正方形搜索窗口的边界惩罚：

$$\mathcal L_{cover}=\operatorname{mean}_{j\in\{x,y\}}\left[\frac{|c_j-\hat c_j|+s^{GT}_j/2-f\hat s/2}{\sqrt{w^{GT}h^{GT}}}\right]_+.$$

这里 $\hat c,\hat s$ 来自实际边界约束后的预测父框，$c,s^{GT}$ 为下一帧GT中心和宽高。训练是连续几何近似，真实裁剪取整、padding和响应干扰在完整评价中另外检验；不宣称覆盖足够就一定跟踪成功。回归项与覆盖项单位化后权重均1，只固定一个先导设置，不做权重/门槛扫描。覆盖惩罚若全程为0，两臂可能完全相同，须如实报告，不能强迫产生不同结果。

原生骨干及适配器不反传梯度。GT只在fit视频损失及完成动作后的评价中使用，在线父框生成不读取GT。

## 训练状态来源与预算

每折每种子固定该折208适配器，在19个fit视频各从首帧完整运行nn和mm两种自身预测状态轨迹。不得用212互补折held轨迹作为训练来源，也不使用213挑出的held失败点。共152条新fit提供轨迹；失败、出裁剪和不恢复状态不按预测质量删去。

每条视频预定最多48个均匀当前时刻，排除最后一帧以保证有下一帧标签；仅排除下一帧标注非有限/宽高非正的样本，并逐源报告数量。两种状态路径拼接，源组等概率，再在源内均匀抽样。归一化也仅用本折fit状态。

2折×2种子×2目标=8模型，每模型256步、batch4，共2048更新。AdamW lr1e−3、weight_decay1e−4、clip_norm1、隐藏宽度32都是事先固定的先导预算，不是理论最优或由held结果挑选；独立状态MLP的学习率不与冻结适配器微调混为同一预算。两目标的初始权重、抽样哈希、归一化哈希、训练参数数量与样本机会必须一致。

此处属于固定提供策略的状态匹配监督，不是迭代on-policy学习、端到端BPTT、PPO或最优控制。若实际学习状态进入未见分布，须在结果中承认并据证据再决定是否需要新一轮状态收集。

## 评价与程序验收

五组：fresh native、nn（raw更新）、mm（adapted更新）、forecast、coverage。除native单路外其余四组同双读出预算，外部输出规则相同；学习组额外计一次小MLP调用。共342条全38源完整OOF轨迹，不能仅选困难片段。

每折首个固定源作为smoke，先18条串行，再18条两个独立spawn worker的短轨迹，框/父框/选择层/调用及非计时诊断数组逐帧完全相同才继续。完整评价默认双进程按视频划分。fresh native/nn/mm须逐帧精确复现同运行身份212控制（排除计时），共190条控制检查。不以回传宏AUC替代状态链验证。

每帧检查parent=上一帧next_parent，下一父框等于该帧raw/适配或该帧MLP输出的确定映射；一次crop/MLP、6前缀block+2候选block、2head，学习组1 updater。实际GT覆盖、网络名义GT侧长、CENTER dense最佳IoU均在在线动作确定后记入诊断，不回馈模型。

主要比较仅预列 `coverage−forecast` 的源组平均AUC，其余学习组对native/nn/mm为支持比较。两种子先源内平均，以38源为单位沿用20000次固定seed bootstrap。42行配对同时记录低IoU、原生与mm匹配恢复/好帧保护；不凭总体AUC采用模型。搜区域统计还区分覆盖但无好网格与好网格漏选。源组仍属历史开发，不是独立外部确认。

产物为12张表、绑定fit NPZ/模型及receipt、完整评价NPZ和decision。接口拒绝变更的来源/已封存产物、非有限训练及错误调用计数；失败后不覆盖旧协议，需审查原因。checkpoint用既有受限加载与哈希/状态身份核验。训练和完整轨迹结果本地未观测，不假称有效。
