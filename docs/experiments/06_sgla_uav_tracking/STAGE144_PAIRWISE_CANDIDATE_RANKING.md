# Stage-144 固定候选池的同帧成对排序

Stage-143 的全网格池在 18 个严重低 IoU 帧中独有好框，逐框预测 IoU 的评分器在这 18 帧均未选中好框。Stage-144 比较逐框 IoU 回归和同帧排序，检验训练时直接比较两个候选能否改善选框。 [Stage-143 结果](STAGE143_RESULTS_REVIEW.md)

## 对照

- 冻结 SGLA 响应、解码、父框和 Stage-142 的两个等预算候选池。复用 Stage-143 的 9 维可观测特征、标准化系数、原始岭回归结果和留出名单。程序逐帧核对 Stage-143 的候选顺序、原生框、原始响应首选、逐框评分和池内真值最优，覆盖 29,047 个原生状态及 240 个分支回放状态。
- 保留 Hann 首选、池内最大原始响应、Stage-143 逐框 IoU 回归和池内真值最优。比较两种共享线性排序器，同一模型用于两个池。推理时每个候选独立得到一个排序分数，选池内最高分，平分沿用候选池顺序。
- 普通排序在同帧、至少一个候选池中共同出现的候选之间配对。两个池共有的配对只计一次。有效且 IoU 不相等的对参与训练，特征差取 IoU 较高框减较低框，目标分差固定为 1。帧内按真值 IoU 差归一化加权，帧与源组逐级等权，岭系数为 0.03。
- 难例排序的训练目标按 50% 普通配对、25% 挽救配对、25% 保护配对加权。挽救配对要求原生 IoU < 0.20，池内好框与 IoU < 0.20 的 Hann 或任一池的原始响应首选比较。保护配对要求原生 IoU ≥ 0.50，以该原生框和 IoU < 0.20 的原始响应首选配对。每折只使用其他 27 个源组的原生状态。分支状态只评估。报告各折实际配对数、来源数和权重。某组留出折若缺少一个难例类别，则按比例重分其余类别权重。

## 判读

报告全部原生帧、两池都有好框的 161 帧、只有全网格池有好框的 18 帧、19 个失跟起点和 240 个分支帧。好框定义为 IoU ≥ 0.50。以同池比较检验成对排序相对逐框回归的变化，并单列加权难例相对普通排序的变化。报告按源组等权的 IoU、好框率与实际选中帧数，在原生状态上报告配对差和区间。对 Stage-143 冻结的 645 个稳定窗口，报告低 IoU 帧和出现连续至少 3 帧低 IoU 的窗口数。

这一轮使用已消耗的开发数据定位选框瓶颈。没有新增图片读取、搜索或状态写回，整段 AUC 和恢复仍需闭环验证。
