# Stage-74：PPO直接选择四个搜索候选

状态：服务器已完成，decision＋11表齐全，`REVIEW_DIRECT_FOUR_CANDIDATE_PPO_PILOT`，见[结果复核](STAGE74_RESULTS_REVIEW.md)。四选一PPO67.2356，对匹配监督+4.0722、两seed均正，对Q+0.9918但区间跨零；0003及0304仍有稳定损伤，保护未过。本页保留结果前固定方案及实现验证历史；按用户要求没有恢复支线，接续[Stage-73复核](STAGE73_RESULTS_REVIEW.md)。

## 1. 问题与可检验的新增价值

旧PPO只决定“保留q0，或接受冻结Q推荐的一个候选”。如果合适候选在另外两个动作中，二元PPO无法直接选择。本轮检验：**开放现有四候选的直接选择，配合实际自身轨迹的累计IoU优化，能否超过同容量的四选一当帧监督及原Q，同时保住原稳定轨迹？**

这里的Q是已训练的当帧质量评分器，不是强化学习Q函数。它在新PPO中只保留诊断记录，不限制动作。预期价值是从“批准已有推荐”转为“直接组织历史搜索候选”，是否带来实际收益由完整轨迹和匹配监督共同检验。采用已有PPO不妨碍研究增量价值；实现完成也不表示该增量已成立。

四候选均差时，本轮没有新增搜索能力。候选支持和漏选比例会同时报告，避免将缺少良好候选与选择错误混为一谈。

## 2. 候选、观测和动作

继续原始SGLA V1／CENTER／VisDrone-SOT，权重、选择器、独立候选块和首帧模板冻结。每帧生成原有四个搜索，每次搜索为6个前缀块＋1个独立候选块，预算不变。四个搜索父框为：

| 候选 | 搜索中心 | 搜索尺寸 |
|---|---|---|
| q0 | 最新预测框中心 | 最新预测框尺寸 |
| q1 | 最新预测框中心 | 既有历史log尺寸的中位数 |
| q2 | 上一个预测框中心 | 最新预测框尺寸 |
| q3 | 上一个预测框中心 | 既有历史log尺寸的中位数 |

短历史沿用原实现回退；每帧用所选候选的实际解码输出推进下一帧，不平滑输出、不用GT重置。

- 输入为现有四候选各64维因果描述，按q0～q3展平为256维；包含响应、几何及既有历史描述，没有新增未来帧或记忆模块。
- 每折仅从该折fit组已有Hann轨迹拟合标准化，各视频等权；scale下限1e−6，标准化后截断至±10。held-out标签不进入标准化或训练。
- actor为256→32 Tanh→4，critic为256→32 Tanh→1，参数独立。每臂actor8356、critic8257，共16613个参数；CPU float64训练控制器，GPU仅执行冻结SGLA。
- 使用masked categorical softmax。**只有完全相同的公开输出框合并到最小索引**，q0始终合法；不按IoU、质量或置信度剔除不同框。四框全相同时强制q0，该状态不计算actor损失。
- 初始输出层为零，在不同输出框上均匀采样；四框均不同时q0初始概率1/4。正式评价取最大概率，平局最小索引。
- actor仅读取当前及历史预测信息；首帧之后的GT只在真实动作／轨迹生成后进入fit奖励、监督标签或离线评价。

与旧二元PPO比较时，输入范围、输入／输出维数、容量和初始探索都会变化。因此这是直接四选一方案的整体比较，**不能解释为仅改变动作数量的纯消融**。新增PPO与新增监督之间则保持这些条件一致。

## 3. 固定训练与对照

来源为完整Stage-73根目录及其绑定的上游产物，结果TXT不能代替模型／NPZ。沿用12个已消耗开发源组、两折每折6 fit／6 held-out、种子2171／2172。按原顺序完成四遍fit视频，按自然视频终点结束，每段后四epoch，minibatch256；固定最后一步，无checkpoint筛选。

| 政策 | 本轮处理 | 作用 |
|---|---|---|
| ppo | 新训练四选一PPO | 本轮主要方案 |
| myopic | 新训练四选一交叉熵 | 同容量／初始化／标准化／曝光／更新次数的当帧监督控制 |
| binary_ppo | 原样复用Stage-73分别裁剪PPO | 旧q0／Q二元动作控制 |
| binary_myopic | 原样复用Stage-73分别裁剪监督 | 旧二元当帧监督控制 |
| quality | 冻结Q | 原四候选当帧质量选择 |
| future | 冻结Stage-68后继增益门控 | 既有后继监督控制 |
| hann | 冻结Hann选择 | 原四候选响应控制 |
| q0 | 始终选择q0 | 原生轨迹保护参考 |

只由新PPO随机采样并生成实时fit轨迹；两个新增训练臂使用这批**完全相同的PPO观测、标签、回报目标和minibatch顺序**，不让监督另采自身fit轨迹。myopic标签为本状态合法候选中的最高当帧IoU，1e−6内并列选最小索引；不为它提供未执行动作的长期回报。它保留相同的value辅助目标和entropy项，区别是actor目标由PPO改为交叉熵。这是同PPO曝光下的目标对照，不代表所有监督学习方案的最优结果。

奖励仍为实际所选框IoU；gamma0.99、GAE lambda0.95、eligible状态上的advantage标准化、PPO clip0.2、value系数0.5、entropy系数0.01。Adam LR3e−4、epsilon1e−5；actor／critic分别norm clip1，同一个Adam管理两个分支。均沿用Stage-73预算，不加warm-start、奖励项、阈值搜索或额外恢复调用。

## 5. 判读与停止规则

主要比较是`ppo_minus_myopic`，同时预定对Q／旧二元PPO／future四个AUC关键比较；报告名义区间及四比较Bonferroni家族区间。另报告对旧二元监督／q0／Hann。先在视频内平均seed，再按12视频bootstrap20000次、seed2171；这些区间条件于反复使用的开发组，不能替代独立确认。

`PROMISING_DIRECT_FOUR_CANDIDATE_PPO_PILOT`需要同时满足：

1. 四个关键AUC家族下界均>0，且对匹配监督及Q平均至少+0.5个百分点。
2. 两个seed各自对myopic／Q／binary_ppo的平均AUC均为正。
3. 原q0稳定视频任一种子均无新增失败；总体低IoU不恶化，可靠帧AUC差名义下界≥−1。
4. 至少四条视频实际选择过不同于q0的输出框，至少四条视频实际选择过q0。

否则为`REVIEW_DIRECT_FOUR_CANDIDATE_PPO_PILOT`。同步查看0304长失跟、0307恢复、0176／0204收益以及其余全部视频，不用总体均值盖住稳定视频损伤。

候选表报告每个动作的使用率、实际输出是否超出{q0,Q推荐}、公开良好候选支持、二元候选支持、当前漏选／regret及良好q0被替为低框。它们是自身轨迹上的离线描述，不是未执行动作的长期因果收益。训练前后概率／label accuracy／value误差使用当段旧行为数据，不冒充新策略回报或独立critic验证。

若四选一只超过旧二元而未超过匹配四选一监督，不能归因于RL累计收益；若无法实际选择二元范围之外的框，则动作扩展的使用证据不足。保留两seed和固定最终模型，不据本轮结果补搜步数／奖励／mask／checkpoint。
