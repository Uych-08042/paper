# 历史实验代码归档

2026-10-29整理时，将当前保留的运行/测试/代码哈希依赖链之外的136个Python文件移至`legacy_tracking/`，包括92个历史脚本和44个测试。所有文件内容与整理前完全一致，SHA256及原路径记录于[整理清单](../docs/maintenance/CLEANUP_MANIFEST.json)。

归档不表示这些方法得到支持；当前研究结论以[工作交接文档](../WORK_HANDOFF.md)为准。归档主要保留早期路由、离线价值、PPO、设备感知等路线，供审计或明确决定恢复时使用。

## 恢复到原路径

在仓库根目录执行：

```bash
python -B tools/restore_legacy_tracking.py
python -B tools/restore_legacy_tracking.py --apply
```

第一条只预览并校验全部源文件；第二条复制全部归档脚本回原`tracking/`路径。归档继续保留。现有目标文件若相同则跳过，若内容不同则在整个复制批次开始前拒绝，避免覆盖后续工作。

旧协议和导入使用原文件名与原目录，因此应先恢复再运行旧阶段；不要直接执行归档目录内的脚本。归档代码未加入活动Python路径。pytest默认跳过此目录。

当前`tracking/`仍保留106个运行/公共模块/测试，包括92个阶段文件。它们是保守依赖集合，不是“只保留Stage-44文件”；删除早期公共模块可能破坏新的冻结来源校验。

归档说明和阶段命令见[文档索引](../docs/README.md)。本次没有重写Git历史、提交或推送。
