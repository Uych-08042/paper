# Stage-149 固定候选准入后的接受分数消融

Stage-148 新放行了两个失跟起点的好框。它们排在备选首位，回归分差与原始响应差使合成分数低于默认框。Stage-149 检验每项分差对是否接受备选的影响。 [Stage-148 结果](STAGE148_RESULTS_REVIEW.md)

## 对照

- 复用 4,754 个冻结状态、原回归默认框和 Stage-148 的准入集合。分差上限为 0.15，框间 IoU 上限为 0.40，要求双方近期颜色与首帧灰度均可用。逐帧核对原三臂的候选、校准门槛及实际决策。
- 保留纯响应与几何、加近期颜色、加首帧灰度三臂。对每种外观各加三臂。分别从原分数去掉回归分差、去掉原始响应加权差、仅保留外观加权差。外观权重和备选并列顺序沿用 Stage-148。消融只作用于准入后的排序与接受。
- 汇报按源组留出校准的结果，以及所有臂只在备选分数严格大于 0 时接受的诊断。校准目标、门槛网格、原稳定窗口保护和已正确起点的保护沿用 Stage-148。校准只用外层留出源组以外的原生状态，并保持校准源组与内层默认框提供者隔离。

## 读数

单报 0085／1541、0089／1159 两处，以及 19 个失跟起点、18 个全网格独有机会和 110 个稳定窗口。区分好框进入比较、排在备选首位、分差转正和最终采纳。记录获益帧、已有好框被改坏的帧、严重低 IoU 与连续低 IoU 窗口。整段跟踪收益仍需闭环评价。

根据 Stage-147／148 已归档的单备选状态复算，两处好框仅用首帧灰度时的分差为 +0.0214 和 +0.0277，均达到零门槛采纳条件。只去掉回归分差或只去掉原始响应差时，两处好框分差仍为负。该复算覆盖两个起点，正式运行会检验按源组校准后的采纳及稳定窗口代价。
