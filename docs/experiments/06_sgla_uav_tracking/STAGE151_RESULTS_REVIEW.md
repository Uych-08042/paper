# Stage-151 写回框中心与宽高交叉对照结果

**只换灰度框的中心、保留回归框的宽高，后继 8 帧平均 IoU 增加 0.0687，32 帧增加 0.0451。** 相反，只换灰度框宽高的均值差为 −0.0664 和 −0.0885。32 帧结果对个别源组敏感。 [实验协议](STAGE151_WRITE_GEOMETRY_CROSS.md) · [服务器原始回传](results/stage151_results_20261120T051054Z_606941.txt)

## 配对结果

| 改动或对照 | 后 8 帧平均 IoU 差 | 后 32 帧平均 IoU 差 |
| --- | ---: | ---: |
| 只换中心，相对回归框 | +0.068707 | +0.045123 |
| 只换宽高，相对回归框 | −0.066419 | −0.088469 |
| 固定灰度宽高，换成灰度中心 | +0.053465 | +0.042807 |
| 固定灰度中心，换成灰度宽高 | −0.081662 | −0.090786 |
| 中心与宽高的交互 | −0.015243 | −0.002317 |
| 写回完整灰度框，相对回归框 | −0.012955 | −0.045662 |

完整后继窗口为 8 帧 12 个起点／7 个源组、32 帧 7 个起点／6 个源组，均值按源组等权。只换中心在两个窗口分别为 7 胜 4 平 1 负和 3 胜 1 平 3 负。逐次去掉一个源组，8 帧均值差范围为 +0.00916 至 +0.08311，32 帧范围为 −0.02262 至 +0.07195。32 帧去掉 0085 源组即转负。

13 个有后继的起点中，次帧已经选到好框（IoU ≥ 0.50）的起点在回归、只换中心、只换宽高、完整灰度四组分别为 1、4、1、1。四组对应的网格无好框数为 2、2、3、2，候选提取漏掉好框数为 2、2、1、1，回归漏选池内好框数为 8、5、8、9。

## 重点个案

| 视频／起点 | 回归后 32 帧 | 只换中心 | 只换宽高 | 完整灰度 |
| --- | ---: | ---: | ---: | ---: |
| 0089／1159 | 0.5880 | 0.5612 | 0.0288 | 0.0620 |
| 0085／690 | 0 | 0.7539 | 0 | 0.7516 |
| 0169／881 | 0.0310 | 0.0277 | 0.4227 | 0.0152 |
| 0348／362 | 0.1472 | 0.0582 | 0.0541 | 0.0211 |

- **0089／1159。** 四组次帧均完整覆盖。换用灰度宽高，裁剪从 66 像素扩大至 104，256 像素输入中的目标短边从 58.18 缩至 36.92 像素。只换宽高的网格最佳 IoU 从 0.7275 降至 0.4044，完整灰度为 0.3575。保留回归宽高、只换中心时，实际次帧 IoU 为 0.5354，次帧起即出现连续好框。
- **0085／690。** 四组次帧均完整覆盖，候选池也都有好框。保持原裁剪边长 325 像素、只换中心时，实际次帧 IoU 从 0 升至 0.7084。只换宽高依然选中 IoU 为 0 的框。中心交换足以在这个起点恢复，提前到同视频 687 帧交换仍未出现连续好框。
- **反例。** 0169／881 只换宽高反而恢复，说明宽高交换的效果因状态而异。0348／362 只换宽高可在次帧选到 0.6550 的好框，32 帧平均 IoU 却低于回归组。一次几何交换后的长期结果仍取决于后继输出。
