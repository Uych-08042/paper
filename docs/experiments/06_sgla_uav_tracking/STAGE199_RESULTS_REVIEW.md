## 探索性分解：主要学到了哪类差异

以下为看到主要结果后增加的描述性分析，不作为新的预设主检验。对每个源视频g，以`z_t=P(y_t−μ)`、`h_t=P(score_t−μ)`分解：

`mean_t ||h_t−z_t||²/6 = ||mean_t h_t−mean_t z_t||²/6 + mean_t ||(h_t−mean h)−(z_t−mean z)||²/6`

第一项是视频平均层偏好误差，第二项是该视频内部随状态变化的误差。恒等式逐视频校验通过，再按视频和种子等权平均。

| 残差模型分量 | 零残差基准误差 | 训练后误差 |
| --- | ---: | ---: |
| fit视频平均偏好 | 0.00026741 | 0.00005344 |
| fit视频内状态变化 | 0.00120760 | 0.00113550 |
| held视频平均偏好 | 0.00036156 | 0.00038323 |
| held视频内状态变化 | 0.00120760 | 0.00121882 |

约74.8%的fit总MSE下降来自视频平均偏好分量；视频内变化分量只降低约5.97%。到held，视频平均偏好分量和视频内变化分量都比零残差基准更差。两折交换同一38组，去掉每视频均值的真实状态变化不依赖fold先验，故fit／held的该能量相同。

这支持下一步研究如何减少对训练视频特有层偏好的依赖，不能单凭分解认定网络记住了视频编号、物理环境是根因，或只增加正则／数据就一定有效。即便fit均值严格受约束，held输入分布的均值也不必为零；held偏好偏移不违反本轮中心化恒等式。

## 下一步建议

建议Stage-200检验**同一视频内两状态的差分监督**，配对一个看到相同状态、同参数和同预算的当前点监督控制。依据是同视频差分会抵消视频平均层偏好，直接检验其是否有助于视频内选择时机的迁移。

若e_t为当前层间残差预测误差，在同视频独立均匀抽两个状态t、s，则`E||e_t−e_s||²/2 = E||e_t−E[e|g]||²`。因此差分损失可对应本轮分解中的视频内项，系数1/2来自方差恒等式，不通过held调权重。训练不需要使用留出视频的均值或标签，也不增加在线历史输入。

新协议应让两组都看到相同的状态对，每更新保持原4个状态引用机会（即2对），统计先验／输入／参数／初始化／更新预算均匹配，保留固定μ和无对应期望控制。不能只看差分训练误差；仍须看held实际IoU、状态对应增量和双种子／源组一致性，再决定完整轨迹验证。差分监督能否改善泛化尚待实验，不是本轮已经成立的新方法。Stage-200仅为建议，尚未实现或运行。

配对抽样会改变一批中状态的相关性，点监督组必须同次按相同状态对重训，不能直接拿本轮旧权重作为唯一公平控制。
